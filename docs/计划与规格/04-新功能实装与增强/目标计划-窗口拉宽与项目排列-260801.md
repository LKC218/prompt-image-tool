| Tauri | `src-tauri/tauri.conf.json` | 1600×900 / min 1024×576 |
| Python/pywebview | `build/app_main.py` | 1600×900 / min 1024×576 |

## A. 拉宽软件窗口

### 现状

`src-tauri/tauri.conf.json`：

```json
"width": 1366,
"height": 768,
"minWidth": 1024,
"minHeight": 576
```

UI 文档与多处响应式断点均按 1366 基准设计；提示词详情双窗口在 `≥1440px` 时左右并排。

### 方案（工程师已确认）

| 项 | 原值 | 新值 | 说明 |
|----|------|------|------|
| `width` | 1366 | **1600** | 更宽主内容区，双窗口并排更从容 |
| `height` | 768 | **900** | 首屏可见更多列表行，减少滚动 |
| `minWidth` | 1024 | 1024 | 不动，兼容小屏 |
| `minHeight` | 576 | 576 | 不动 |

### 影响面

- 仅改 Tauri 启动默认尺寸，不影响响应式布局逻辑
- 现有断点（1180 / 1240 / 1280 / 1440）全部在新默认宽度之下，布局只会更舒展，不会触发降级
- 浏览器开发模式（Vite）不受此配置影响，属预期

### 改动文件

| 文件 | 改动 |
|------|------|
| `src-tauri/tauri.conf.json` | `width` / `height` 两个字段 |

### 验收

1. `npm run tauri dev`（或打包安装后）启动，默认窗口为 1600×900
2. 拖拽窗口到 1024 宽仍可正常使用
3. 提示词详情页在默认宽度下双窗口自动左右并排
4. 目标计划、分类、设置等页面无横向溢出或元素重叠

## B. 项目排列功能

### 现状

- `pc-goal-projects.js` 按 `order` 字段排序，用户无法调整
- 项目「更多」菜单仅有：设置封面 / 重命名 / 复制 / 删除
- 存储层 `sqlite-storage.js` 已有 `sort_order` 字段与 `updateGoalProject(id, { order })` 接口

### 方案：仅排序菜单（工程师已确认，轻量前端重排）

在「我的项目」标题行右侧新增排序入口按钮（图标复用 `arrow-up-down`），点击弹出 `showContextMenu`：

| 菜单项 | 排序键 | 方向 |
|--------|--------|------|
| 默认顺序 | `order` | 升序 |
| 按名称 | `name` | 升序（localeCompare） |
| 按创建时间 | `createdAt` | 降序（新→旧） |
| 按更新时间 | `updatedAt` | 降序（新→旧） |
| 按进度 | `progress` | 降序（高→低） |
| 按存储大小 | `imageBytes` | 降序（大→小） |

行为约定：

- 排序偏好存 `localStorage`（key：`pc-goal-project-sort`），刷新后保持
- **仅前端重排显示**，不改写数据库 `sort_order`
- 选中当前排序项时菜单项标记 `aria-checked` / 选中态

### 改动文件

| 文件 | 改动内容 |
|------|----------|
| `src/js/pc-goal-projects.js` | header 加排序按钮；实现 `applyProjectSort()`；菜单项与 localStorage 读写 |
| `src/css/pc/08-goal-plan.css` | header 排序按钮样式（含选中态/暗色） |
| `docs/模块说明/目标计划模块.md` | 补充「项目排序」交互说明 |

无新增依赖。

### 验收

1. 点击排序按钮弹出 6 个菜单项，切换后列表立即按目标键重排
2. 刷新页面后排序偏好保持
3. 当前排序项在菜单中有选中标记
4. 暗色主题下排序按钮视觉一致

## 风险与约束

1. **1600×900 与 1366 屏**：系统可能缩放窗口；`minWidth` 保持 1024，用户仍可手动收窄
2. **浏览器 vs Tauri**：窗口尺寸仅在 Tauri 生效；排序功能两端一致
3. **不改数据库结构**：纯前端排序，零迁移、零写库

# 图片无损压缩实施计划

## 授权与范围

采用已评审的方案一批量工作台。用户授权本轮自动实施、启动服务及视觉验收。首期仅 PC，不改已有图库转码策略，不覆盖原图，不操作现有真实数据服务。

## 设计

- 独立 `/compress` 页面：批量图片、文件夹、文件拖放、去重、选择、移除、重试、取消。
- Python 独立接口调用固定 Oxipng 10.2.1，标准与深度两档；一次处理一张，限制线程、输入、像素量及时间。
- 使用 `--nx` 保留位深、颜色类型及交错方式；禁用透明像素修改和元数据剥离。独立解码像素比对，非 IDAT 数据块逐项保留校验。
- APNG 明确拒绝。无收益保留原文件；保真失败不得输出未经验证的候选。
- 单图导出 PNG 副本；批量导出 ZIP，安全处理相对目录、重名文件。不上传至外部服务。
- 复用应用侧栏、主题服务、语义令牌；路由卸载取消任务并释放对象地址。
- 本地接口限制来源、请求大小与任务并发，不占全局数据写锁。

## 验收边界

验收包含透明、16 位、调色板、元数据、损坏文件、APNG、无收益、取消、重复文件及 ZIP 回读。UI 包含浅深色、六主题、窄屏、键盘焦点、减少动态效果。Web 验收与 Windows 安装包运行验收分别报告，不将构建成功当作安装包验收。

## 风险边界

严格保留非 IDAT 块会牺牲部分压缩率；文件已优化时可能没有收益。浏览器队列与结果有内存上限，刷新会丢失当前队列。安装包必须携带固定引擎和许可，不允许运行时自动从网络取可执行文件。

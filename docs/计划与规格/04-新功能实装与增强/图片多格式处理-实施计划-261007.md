# 图片多格式处理-实施计划

## 已确认范围

在既有方案一工作台上增加 PNG、JPEG、静态 WebP 的混合批量压缩与格式转换；保留详细强度面板与统一横幅。原图只读，明确有损和元数据边界；梳理缓存并提供过期缓存清理。用户已确认开始实施，不包括安装包发布。

## 实施顺序

1. 独立图片处理 API 与工作进程，复用 PNG 严格保真路径；准备并校验 JPEG 无损引擎，固定 Pillow。
2. 专属临时目录与活跃租约锁；处理完成回收，过期异常任务安全清理；限制输入、输出和打包体积。
3. 扩展原设置面板，按条件展示目标格式、质量、透明填充和元数据确认；保持列表简洁。
4. 原格式优化、全格式转换矩阵、异常输入、元数据、取消、缓存测试；服务器与浏览器实际处理、导出回读、截图检查。
5. 同步代码地图、模块说明、API、脚本 README、验收与经验记录；记录许可和安装包尚未验证的边界。

## 验收原则

无损需比较像素和元数据，不以体积减少或成功响应代替验证。转换需回读真实格式、尺寸与透明行为。缓存清理不得触及原图、图库、未知目录或活跃任务。视觉验收覆盖浅深色和 800／1024／1280／1440 宽度；完整构建不等同安装包运行验收。

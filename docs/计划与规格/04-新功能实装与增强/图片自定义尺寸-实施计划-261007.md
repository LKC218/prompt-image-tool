# 图片自定义尺寸实施计划

## 范围与约束

在 PC 图片处理页为 PNG、JPEG、静态 WebP 增加独立尺寸开关；默认关闭、锁定比例、仅缩小。不包含裁剪、补边、水印、固定体积及全站改造。原图只读，保留当前工作区和现有服务。

## 实施方案

1. 前后端独立实现同一纯尺寸规则，以共用样例交叉验证。指定尺寸支持单边推导、双边等比放入、解锁精确尺寸；百分比和最长边互斥。正数四舍五入、至少一像素。
2. 参数边长为 1–16384 整数，百分比为 0.01–1000（最多两位小数）；输入及最终输出不超过 1600 万像素。仅缩小时等比倍率不超过 1；解锁时分别限制两轴不超过原图。
3. 以 EXIF 显示方向计算；实际缩放先一次性归正方向再重采样，清理失效方向／尺寸元数据并报告。高位深和特殊颜色模式保守拒绝。JPEG 实际缩放明确重新编码质量，输出变大不回退。
4. 参数置于编码之后、优化等级之前，窄面板按模式显示字段；逐图展示原尺寸、预计尺寸和已有结果实际尺寸。调参不触发编码。
5. 沿用缓存、取消、超时、ZIP、安全路径和内存限制。关闭开关保持旧处理契约。

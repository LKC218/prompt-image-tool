# PC自定义光标圆环柔光重构实施计划

> 版本：1.0 | 创建日期：2026-09-15 | 状态：待实施
>
> 范围：PC 端自定义光标视觉与交互重构；不调整业务页面结构、路由与移动端光标策略。
>
> 参考：[CodePen · Custom cursor hover effect](https://codepen.io/ihelai/pen/vwPMYE)（圆环 + 悬停柔光）

---

## 一、决策摘要

### 1.1 目标形态

完全替换现有「四角取景框 + 空闲自转 + 语义 glyph」方案，改为：

| 状态 | 视觉 |
| --- | --- |
| 空闲 | 品牌色描边圆环，约 28px，半透明或无填充 |
| 可点悬停 | 放大至约 44px，低透明品牌色填充 + 轻微 `blur`，形成柔光晕 |
| 按下 | 略缩小（约 24px） |
| 禁用 / 加载 | 降透明或细环，不引入图标字符 |
| 输入框 / `native` | 隐藏自定义光标，保留浏览器原生光标 |

### 1.2 已确认决策

1. **完全按 Pen 思路替换**：去掉四角框、空闲自转、目标框吸附、Unicode 图标语义。
2. **主色跟主题**：描边与填充统一使用 `--color-brand-primary`（缺失时回退 `#2477d4`）。
3. **对外 API 不变**：继续导出 `initPcCursor(root)` / `supportsCustomCursor()`，`pc-app.js` 调用点零改动。
4. **模板 `data-cursor` 本次不批量清理**：JS 降级解析即可；后续可单独治理标记冗余。

### 1.3 不做什么

- 不保留 media/favorite/menu/copy/drag/zoom 等图标语义。
- 不做目标元素四角吸附与每帧 parallax。
- 不照搬 Pen 的 `setInterval(100ms)` 轮询跟随。
- 不改移动端策略（仍由 `supportsCustomCursor` 门禁屏蔽）。

## 二、现状与问题边界

### 2.1 现有实现

| 模块 | 位置 |
| --- | --- |
| 逻辑 | `src/js/pc/pc-cursor.js` |
| 样式 | `src/css/pc/01-foundation-shell.css`（约 170–379 行） |
| 测试 | `src/js/pc-cursor.test.js` |
| 调用 | `src/js/pc/pc-app.js`（`import` + `initPcCursor(appEl)`） |
| 模块说明 | `docs/模块说明/PC端自定义光标模块.md` |

结构：中心点 + 状态 glyph + 四角括号；空闲 4s 自转；悬停可交互目标时四角飞出框住元素。

### 2.2 已确认问题

1. **叠影 / 错位**：GSAP `x/y` 与 CSS 角点 `transform: translate(%)` 抢同一 transform，状态切换与 `setTarget(null)` 交错时出现双框、折线。
2. **空闲态对比度不足**：浅色底上白色点/角几乎不可见。
3. **视觉噪音**：自转 + 四角 + Unicode glyph（★/•••/□/×）与卡片列表语言冲突。
4. **性能偏重**：`renderTargetParallax` 每帧多次 `getBoundingClientRect` / `gsap.getProperty`。
5. **语义状态机过重**：9+ 状态与模板标记耦合，维护成本高、收益低。

### 2.3 参考 Pen 拆解

| 项 | Pen 做法 | 本项目采用 |
| --- | --- | --- |
| 结构 | 单个 `#cursor` 圆环 | 采用（单节点） |
| 悬停 | TweenMax 放大 + blur + 半透明填充 | 采用，颜色改品牌色 |
| 跟随 | `setInterval` 100ms 改 `left/top` | **不采用**；改 GSAP `quickTo` |
| 坐标 | `pageX/Y` + `absolute` | **不采用**；`clientX/Y` + `fixed` |
| 原生光标 | 不隐藏 | 沿用项目 `cursor: none` + native 回退 |
| 主色 | 固定黄 | 跟 `--color-brand-primary` |

## 三、实施方案

### 3.1 重写 `src/js/pc/pc-cursor.js`

**保留：**

- `(hover: hover) and (pointer: fine)` 与 `prefers-reduced-motion: reduce` 门禁
- `data-cursor="native"`、可编辑输入框回退
- `disabled` / `aria-disabled` / `aria-busy` 识别
- 指针离开、窗口 blur、`destroy` 生命周期
- 单例 `activeController` 重复初始化先销毁

**删除：**

- `IDLE_CORNERS`、`animateCornersToTarget`、`getCornerTargets`
- `setIdleSpin` 与空闲自转
- `renderTargetParallax`、目标 `ResizeObserver`
- 语义 glyph 状态（favorite/menu/copy/drag/zoom/media 等）
- 与 CSS `%` translate 冲突的角点逻辑

**新 DOM：**

```html
<div class="pc-custom-cursor" aria-hidden="true"></div>
```

**状态 class：**

| class | 含义 |
| --- | --- |
| `is-custom-active` | 进入应用区域，光标可见 |
| `is-hover` | 命中可点目标（放大 + 柔光） |
| `is-pressed` | 按压 |
| `is-disabled` | 不可用 |
| `is-loading` | 加载中 |
| 根节点 `pc-custom-cursor-native` | 隐藏自定义层，恢复原生 |

**可点判定（简化）：**

优先级：`native` / 输入类 → native；`disabled` → disabled；`aria-busy` → loading；其余 `button, a[href], [role="button"], [data-ripple], [data-nav], cursor:pointer` 等 → hover。

**跟随：**

```js
const setX = gsap.quickTo(cursor, 'x', { duration: 0.16, ease: 'power3.out' });
const setY = gsap.quickTo(cursor, 'y', { duration: 0.16, ease: 'power3.out' });
```

**居中约定（避免二次 transform 冲突）：**

- 初始化：`gsap.set(cursor, { xPercent: -50, yPercent: -50 })`
- 每帧只更新 `x/y`（视口坐标），禁止再写 CSS `translate(-50%,-50%)` 与 GSAP x/y 混用

**建议默认尺寸（实现时可微调）：**

| 状态 | 尺寸 | 动效 |
| --- | --- | --- |
| 空闲 | 28px | — |
| hover | 44px | 0.18s `power3.out` |
| pressed | 24px | 0.1s |
| 跟随 | — | `quickTo` 0.16s |

### 3.2 替换 `src/css/pc/01-foundation-shell.css` 光标段

- 删除 `.pc-custom-cursor-corner` / `.pc-custom-cursor-glyph` / media-target 及相关 keyframes
- 保留 `cursor: none`、native 回退、输入框 `cursor: text`
- 新样式要点：

```css
.pc-custom-cursor {
  position: fixed;
  top: 0;
  left: 0;
  width: 28px;
  height: 28px;
  border-radius: 50%;
  border: 2px solid var(--color-brand-primary, #2477d4);
  background: transparent;
  pointer-events: none;
  z-index: 2147483647;
  opacity: 0;
  transition: opacity 120ms ease;
  will-change: transform;
}

.pc-custom-cursor.is-hover {
  width: 44px;
  height: 44px;
  background: color-mix(in srgb, var(--color-brand-primary, #2477d4) 22%, transparent);
  filter: blur(6px);
}
```

- blur 仅在 hover 开启，离开关闭，避免常驻影响合成
- 颜色全部走 Token，主题切换无需 JS 重绘

### 3.3 重写 `src/js/pc-cursor.test.js`

删除四角 / 语义 glyph 断言，覆盖：

1. 精细指针创建单节点，按钮 hover → `is-hover`
2. 输入框 → 关闭自定义光标 + native
3. `data-cursor="native"` 优先
4. disabled / loading 对应 class
5. pointerdown / pointerup → `is-pressed`
6. destroy 移除节点与根 class
7. reduced-motion 或非 fine pointer → 返回 `null`

## 五、风险与边界

| 风险 | 应对 |
| --- | --- |
| blur 影响合成性能 | 仅 hover 进入时开启，离开立即移除 |
| GSAP transform 与 CSS 再次冲突 | 统一 `xPercent/yPercent` + `x/y`，禁止混写 CSS translate |
| 浅色/深色主题对比度不足 | 描边用品牌主色；必要时深色模式提高透明度或加细描边 |
| 输入框 / 原生缩放边缘 | 沿用 native 门禁与 `NATIVE_CURSOR_VALUES` |
| 模板冗余 `data-cursor` | 本次不清理；后续独立治理 |
| 与页面自身 hover 样式叠加 | 新实现不给目标加 `pc-custom-cursor-target` 视觉副作用 |

**不在本计划内：**

- 移动端光标策略
- 页面卡片 hover 阴影/位移等业务动效
- 批量删除或重写各页面 `data-cursor` 标记

## 六、验收标准

1. PC 精细指针下全局可见品牌色圆环，浅色背景可辨识。
2. 悬停可点控件出现放大 + 柔光，移出后恢复空闲态。
3. 输入框、`data-cursor="native"`、禁用、加载行为符合约定。
4. 不再出现双角框、折线叠影、空闲自转。
5. `npm test` 通过；`initPcCursor` 对外签名不变。
6. 模块说明文档与代码一致。

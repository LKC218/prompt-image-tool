# 设计系统

全局视觉语言、主题令牌与组件级设计规范。页面级方案见 [页面与UI](../页面与UI/)。

## 放什么 / 不放什么

- **放**：主题 Token、配色、全局组件规范、设计语言（新拟态、光标等）。
- **不放**：单页布局稿、安装器壳页面规则、生图提示词、会话过程稿。

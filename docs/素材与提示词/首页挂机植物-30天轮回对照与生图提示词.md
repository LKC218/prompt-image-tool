# 首页挂机植物 · 30 天轮回对照表与生图提示词

> 配套：`plant-idle-game`  
> 模型：真实日历 30 天一轮（生长 → 开花 → 凋落 → 铲除重开）  
> 养护（浇水/施肥/除害）**不加速生长**，只做交互反馈  
> 每天可见差异 = **阶段整图 + 按 dayIndex 的确定性装饰/姿态**

---

## 1. 术语

| 符号 | 含义 |
|------|------|
| `day` | 本轮第 1–30 天（`cycleStartAt` 起算） |
| `stage` | 整图档位（共 12 张） |
| 装饰 | 露珠/瓢虫/落叶/额外花等，按天固定出现 |
| 姿态 | CSS `rotate` / `scale` / 轻微色相，按天固定 |

## 3. 完整 30 天对照表

姿态约定（代码可直接抄）：

```text
tilt  = ((day * 17) % 7) - 3          // -3° ~ +3°
scale = 0.97 + ((day * 13) % 7) * 0.01 // 0.97 ~ 1.03
hue   = ((day * 5) % 3) - 1            // -1 / 0 / +1 → 轻微色相
```

### 3.1 装饰出现频率汇总

| 装饰 | 出现 day |
|------|----------|
| 露珠 dew | 2,4,7,11,14,17,20,24 |
| 瓢虫 bug | 5,10,15 |
| 蝴蝶 butterfly | 8,13,18,22,25 |
| 额外花 flower | 20–26（数量见表） |
| 落叶 leaf-fall | 27–30 |

### 3.2 交互与生长解耦

| 操作 | 冷却 | 视觉 | 改 day/stage？ |
|------|------|------|----------------|
| 浇水 | 每日 1 次 | 水滴粒子 + 叶面高光 ~2h | 否 |
| 施肥 | 每日 1 次 | 土面光点 + 略鲜绿 ~2h | 否 |
| 除害 | 瓢虫出现时 | 点掉 bug，播放消失 | 否 |
| **铲除** | day≥30 或枯死后 | 推土动画 → `cycleStartAt=now` | **是，重置** |

## 5. GPT 生图提示词

### 5.1 风格锁（每条必带）

```text
扁平厚涂儿童绘本风，柔和马卡龙色，圆润造型，无写实阴影，
背景透明或纯浅蓝 #EAF3FF，居中单盆栽，无文字无水印，
与「云朵天际 + 柯基吉祥物」App 插画同一审美
```

**负面词：**

```text
写实摄影、复杂背景、阴影过重、卡通脸、拟人五官、文字、水印、
多株植物、暗黑风、赛博、3D噪点、圣诞树尖塔、荧光绿、塑料感
```

### 5.2 统一角色（镜面草，每条阶段图前置）

```text
同一株镜面草盆栽：陶土色圆润小花盆，浅色口沿，深色营养土，
茎细而挺，圆盘形叶片带短柄，叶片略厚、边缘圆滑，
主色 #6BC98A 到 #5BBF7A，茎 #4FA86B，盆 #E8B48A
花盆造型、色板、叶片形状全程保持一致，只改变植株大小、密度、花与枯萎状态
```

### 5.3 阶段整图 12 条

拼接规则：`§5.1 风格锁 + §5.2 统一角色 + 下列正文 + §5.1 负面词`  
尺寸：`1024×1024`，透明底优先。

#### 01-seed
```text
只有花盆和土面，土中央 1 个极小绿色芽点，几乎贴土，
构图极简，植株占画面下方 1/4，上方大量留白
```

#### 02-sprout
```text
短茎约画面高度 1/4，左右 2–3 片小圆叶，叶片直径小于盆口，
整体矮胖可爱，像刚买的迷你桌盆
```

#### 03-young
```text
茎约画面高度 1/3，圆叶 4–6 片沿茎交替，冠幅仍小于盆口直径，
清新幼株，无花
```

#### 04-juvenile
```text
茎约画面高度 2/5，圆叶 7–10 片，冠幅约等于或略大于盆口，
开始出现圆形轮廓，无花
```

#### 05-mid
```text
茎约画面高度 1/2，圆叶 11–15 片，形成明显圆冠，
叶片有前后遮挡，盆仍清晰，无花
```

#### 06-lush
```text
茎约画面高度 3/5，圆叶 16–20 片，冠幅饱满圆润、外轮廓接近正圆，
健康茂盛，无花
```

#### 07-full
```text
植株接近撑满画幅高度约 80%，圆叶密集、层次丰富，
冠幅宽、盆仅露出上半，仍无花或仅 1 个极小花苞
```

#### 08-peak
```text
成熟峰：冠幅最饱满，圆叶最多且圆润，
顶部出现 1–2 个浅粉小花苞或刚开的小花，氛围治愈
```

#### 09-bloom
```text
开花期：茂盛圆冠上点缀 2–3 朵浅粉五瓣小花，花心淡黄，
叶片仍鲜绿，整体像节日状态
```

#### 10-bloom-full
```text
盛花：3–4 朵浅粉小花均匀分布在冠顶与侧面，
植株最精神、最华丽，略带柔光，是整轮最美的一帧
```

#### 11-wilt
```text
初萎：叶片整体下垂、颜色偏黄绿、失去高光，
仍有少量残花或花瓣欲落，花盆不变，略显疲态但未焦枯
```

#### 12-dead
```text
枯萎：多数叶片焦黄卷曲或已落，仅剩少量枯叶与细茎，
土面可见，花盆完整，等待被铲除重来的状态，不阴森、保持绘本柔和
```

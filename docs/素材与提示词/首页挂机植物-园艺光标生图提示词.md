# 首页挂机植物 · 园艺光标生图提示词

> 用途：植物小游戏交互区悬停时切换的专用光标素材。  
> 风格：与镜面草扁平绘本、云朵横幅一致。  
> 实现建议：`cursor: url(...) x y, auto`，仅 `.pc-plant-slot` 生效。

---

## 1. 设计原则

| 项 | 建议 |
|----|------|
| 作用范围 | 仅植物槽 / 养护气泡 / 特效按钮，**不改全局光标** |
| 尺寸 | 素材约 64×64，CSS 显示 28–32px |
| 热点 | 铲/壶嘴对准 `cursor` 的 hotspot 坐标 |
| 状态 | 默认 1 张即可；可选按按钮 hover 再换 2–3 张 |
| 可访问性 | 保留 `pointer` 兜底；`prefers-reduced-motion` 不影响光标图 |

## 3. 风格锁（每条必带）

```text
扁平厚涂儿童绘本风，柔和马卡龙色，圆润造型，无写实阴影，
透明背景，单元素居中，清晰小尺寸可读，
```

## 5. CSS 接入示意（图到后）

```css
.pc-plant-slot,
.pc-plant-trigger {
  cursor: url('/src/assets/pc/plant/fx/cursor-leaf.png') 4 4, pointer;
}

.pc-plant-care-btn[data-plant-care="watered"] {
  cursor: url('.../cursor-water.png') 8 8, pointer;
}
/* 施肥 / 除害 / 铲除 同理 */
```

注意：`url()` 需用构建后可达路径（Vite import 后注入）。

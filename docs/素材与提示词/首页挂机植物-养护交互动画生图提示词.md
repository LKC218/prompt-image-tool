> **MVP 可不生**，纯 CSS 已能做；本文档供你要「更插画感」时使用。  
> 配套：`docs/素材与提示词/首页挂机植物-30天轮回对照与生图提示词.md`

## 3. 风格锁（每条必带）

```text
扁平厚涂儿童绘本风，柔和马卡龙色，圆润造型，无写实阴影，
透明背景，单元素居中，无文字无水印，
与「云朵天际 + 柯基吉祥物 + 镜面草盆栽」同一审美
```

**负面词：**

```text
写实摄影、复杂背景、文字、水印、拟人五官、暗黑风、3D噪点、塑料感、描边过重
```

---

## 4. 分条提示词

拼接：`§3 风格锁 + 下列正文 + §3 负面词`

### water-drop.png

```text
一颗晶莹的浅蓝色水滴，上尖下圆，内部有极淡高光，
边缘柔和半透明，适合从植物上方落下做浇水动画，
尺寸小、清晰，透明底，无叶片无盆无手
```

### sparkle.png

```text
一颗四角或六角的淡金色小星光，中心略亮，边缘柔虚，
扁平插画风，适合叠在土面做施肥闪烁，透明底，无背景
```

### dust.png

```text
一小团浅棕色/米色扬尘或土雾，边缘松散柔和、半透明，
卡通绘本风，适合铲除时从盆口扬起，透明底，无铲无手
```

## 5. 与动画的对应关系

| 交互 | 有图时 | 无图（CSS 兜底） |
|------|--------|------------------|
| 浇水 | 3–4 个 `water-drop` 从冠顶落下淡出 | 蓝色圆点 `@keyframes` 下落 |
| 施肥 | 2–3 个 `sparkle` 在土面闪现淡出 | 淡金圆点 scale 闪烁 |
| 除害 | `bug.png` scale→0 | 同（已有图） |
| 铲除 | 整株淡出 + `dust` 扬起 | 整株 `scaleY` 压扁淡出 |

养护**不改变** `cycleDay`，仅播动画。

## 6. 验收

- [ ] 三张均为透明底、单元素、风格与镜面草一致  
- [ ] 缩到 16–24px 仍可辨认  
- [ ] 与已有 `fx/` 色板不冲突（浅蓝水滴 / 淡金星光 / 米色土雾）  
- [ ] 无文字、无水印

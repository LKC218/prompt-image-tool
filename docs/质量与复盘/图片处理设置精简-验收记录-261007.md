# 图片处理设置精简验收记录

## 范围

仅调整 PC 图片处理设置的分组、显隐、文案和比例锁布局；不修改后端算法、API、缓存处理、图片尺寸规则或数据持久化。不缩小字体与数字框，不改面板内宽、收展动画、固定标题及独立滚动。没有提交、推送、发布或清理用户文件。

## 信息密度实测

同一 1440×1050 视口、三张合成混合图片、减少动态效果模式，修改前后分别采集设置滚动区内可见内容的首尾边界高度。数值不是整个侧栏高度，也不代表所有窗口与参数组合。

| 状态 | 修改前 | 修改后 | 高度减少 |
| --- | --- | --- | --- |
| 默认原格式处理 | 697px | 393px | 43.6% |
| 开启尺寸，单宽 160 | 1264px | 818px | 35.3% |
| PNG 转换并调整尺寸 | 1215px | 731px | 39.8% |

原始数据：`output/image-settings-density/调整前.json`、`验收结果.json`。没有把所有参数折叠藏起：格式、有效编码／质量、尺寸与四档预设仍直接操作；精确等级、线程／预算、缓存维护与恢复默认进入高级设置。

## 本轮验证

- 前端全量：50 个测试文件、460 项通过，含新增 8 项页面设置测试。日志 `output/image-settings-density/frontend-tests.log`。
- 专项浏览器 `verify-image-settings-density.mjs`：显隐、所选批次相关质量、比例锁键盘、详情展开不代替确认、自定义等级摘要、高级参数折叠保值、缓存操作、参数实际发送、3 张真实混合缩放通过；页面无脚本错误。
- 原有 `verify-image-processing.mjs`、`verify-image-interactions.mjs`、`verify-image-panel-motion.mjs`、`verify-image-resize.mjs`、`verify-png-compression.mjs` 全部重新通过。仅更新了控件迁移后的定位／展开步骤，未删除原输出和交互断言。
- 5 个尺寸 ZIP 共 15 张结果经 Python 独立回读，格式、实际尺寸、方向和透明值通过；原 PNG ZIP 7 张的像素与非图像元数据一致。
- 实际查看默认设置、PNG 转换尺寸、浅色宽屏和深色窄屏截图；没有全页横向溢出，保持窄屏覆盖、宽屏并排。截图位于 `output/image-settings-density/`。
- `npm run build`、`verify:dist-assets` 和 `git diff --check` 通过。输出目录经 `git check-ignore` 确认已忽略，无需放宽或修改 `.gitignore`。

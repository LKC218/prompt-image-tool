# 工程目录说明

本文说明项目主要目录职责，用于新增文件时快速判断放置位置。

## 根目录

根目录只放项目级配置、依赖清单和必要的一键入口脚本。

应保留：

- `package.json`
- `package-lock.json`
- `vite.config.js`
- `capacitor.config.ts`
- `requirements.txt`
- `.gitignore`
- `README.md`
- 必要的启动和构建脚本，例如 `build.bat`、`dev.bat`

不建议长期放置：

- 历史计划文档
- 安装包产物
- 一次性工具脚本
- 临时调试文件

## `src`

前端源码目录，也是 Vite 的 `root`。

主要内容：

- `src/index.html`
- `src/css`
- `src/js`
- `src/assets`

`src/js` 按功能域分组（2026-09-23 起），新增文件请放进对应子目录：

| 目录 | 职责 |
| --- | --- |
| `src/js/main.js` | 应用入口：探测 UI、初始化主题与存储、挂载 PC/移动壳 |
| `src/js/core/` | 存储抽象（API/SQLite）、基础工具、主题、版本号 |
| `src/js/shared/` | 跨端共享：备份、图片、标签、文件夹颜色、导入、下载历史、涟漪、教程 |
| `src/js/pc/` | PC 壳、路由、页面、弹窗与专属组件 |
| `src/js/mobile/` | 移动壳、路由、页面与移动端收藏反馈 |
| `src/js/plant/` | 首页挂机种植物（逻辑/存档/计时/渲染） |
| `src/js/goal/` | 目标计划共享逻辑（清单工具、脑图核心、图片预览） |
| `src/js/games/` | 小游戏纯逻辑（俄罗斯方块、飞机大战） |
| `src/js/release/` | 更新记录与应用内自动更新 |
| `src/js/sync/` | 局域网同步客户端 |

测试文件与被测模块同目录（`*.test.js`）。跨组引用使用相对路径，例如 `../core/storage.js`。

新增前端页面、样式、交互模块和前端资源时，优先放在这里。

## `python`

Python 后端、测试与历史运行时数据迁移目录。

主要内容：

- `python/main.py`
- `python/tests`
- `python/data/.gitkeep`

新增后端接口、数据处理逻辑和 Python 测试时，优先放在这里。

`python/data` 仅保留 `.gitkeep` 并作为历史开发数据迁移来源。Windows 真实提示词数据、图片和备份默认存储在 `%APPDATA%\PromptImageManager\data`，不进入 Git；首次运行时缺失的数据文件由程序按空数据处理，保存或备份时自动创建所需目录。

## `src-tauri`

Tauri 桌面端工程目录。

新增桌面端权限、Rust 逻辑、Tauri 配置和桌面图标资源时，优先放在这里。

## `android`

Capacitor Android 工程目录。

仅在需要修改 Android 原生配置、权限、图标、启动屏或 Gradle 配置时编辑该目录。

## `UI设计稿` 与 `gpt本地档案馆工具`

旁支目录，不参与主应用 Vite/Tauri/Capacitor 构建：

- `UI设计稿/`：历史 UI 复刻稿、插画/图标源资产、目标计划脑图视觉参考；运行时资源在 `src/assets/`。
- `gpt本地档案馆工具/`：ChatGPT Vault 用户脚本，导出数据供本工具导入。

## `docs`

项目文档总目录。分类规范见 [docs/README.md](../README.md)。

推荐分类（2026-09-18 起）：

- `docs/导航`：全局文件导航（apps-code-map）与项目代码百科。
- `docs/工程指南`：交接、迁移、目录职责、发版维护流程。
- `docs/技术文档`：API、PC、移动端、Web 和局域网同步技术说明（路径稳定）。
- `docs/设计系统`：主题 Token、全局组件与视觉规范。
- `docs/页面与UI`：页面级 UI 方案、端侧布局、复刻稿。
- `docs/模块说明`：就近模块说明，功能改动后优先同步（路径稳定）。
- `docs/构建方案`：PC、Android 等构建方案（路径稳定）。
- `docs/版本记录`：changelog 权威源与更新说明规范（路径稳定，脚本依赖）。
- `docs/计划与规格`：活跃实施计划 + compose 功能规格。
- `docs/质量与复盘`：测试记录、已修复问题、经验沉淀。
- `docs/素材与提示词`：生图提示词与美术素材对照。
- `docs/assets/readme`：GitHub README 首页展示素材（路径稳定）。
- `docs/_归档`：已完成/过期/一次性材料，不参与日常导航。

**路径稳定**（勿随意改名）：`技术文档/`、`构建方案/`、`版本记录/`、`模块说明/`、`assets/`。

## `build`

Tauri 发包与 Sidecar 打包相关（见 [PC发包规范-Tauri主路径](../构建方案/PC发包规范-Tauri主路径.md)）。

- 正式：`server.spec`、`auto_update.py`、`icon.ico`、`probe_install.py`
- DEPRECATED 旧壳（禁止发包）：`app.spec`、`app_main.py`、`installer.nsi`

安装包、日志和 `_` 前缀临时文件不进入 Git；本地只保留最新 1–2 个安装包便于验证。

## `releases`

发布产物归档目录。

仅作为发布产物落点，Git 中只保留 `.gitkeep` 占位文件。安装包应通过本地构建产物或 GitHub Releases 分发，不直接提交到仓库。

本地维护约定：日常只保留 `latest.json`、`.gitkeep` 与当前最新版 `PromptImageManager-Setup-<ver>.exe`；旧版安装包与过期发布说明在对应 GitHub Release 上传后即可删除，避免目录无限膨胀。正式分发以 GitHub Releases 为准。

## `scripts`

专项维护脚本目录。清单与用法见 [scripts/README.md](../../scripts/README.md)。

常用入口：

- `scripts/start_dev_server.py`：本地开发服务器
- `scripts/build_pc_package.py` / `build_android_package.py` / `build_release_packages.py`：构建
- `scripts/publish_release.ps1`：一键发布
- `scripts/verify-*.mjs`：本地核验

这些脚本通常有副作用，运行前应先检查工作区状态。

`scripts/reorg_src_js.py` 与 `scripts/fix_test_paths.py` 为一次性 `src/js` 分组迁移脚本，仅在需要重放迁移时使用。

创建前应同步修改引用脚本和构建文档。

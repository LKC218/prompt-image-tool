# 路由与启动模块

## 职责

本模块负责按运行环境选择 PC 或移动端应用，并在单页应用会话内协调页面切换、浏览器 History 状态与启动恢复。

## 源码入口

- `src/js/main.js`：根据 `?ui=pc`、`?ui=mobile`、容器和视口条件加载对应应用。
- `src/js/pc-app.js` / `src/js/mobile-app.js`：注册页面、挂载应用壳，并按路由器恢复的首个路由创建页面与同步导航状态。
- `src/js/pc-utils.js` / `src/js/mobile-app.js`：提供跨页面动作菜单能力。PC 使用最多两层的级联上下文菜单，移动端将含 `children` 的动作项渲染为带返回入口的分层动作表。
- `src/js/pc-router.js` / `src/js/mobile-router.js`：维护内存路由、业务返回栈与浏览器 History 快照。

## History 契约

- 每个同端 History 条目包含 `view`、`path`、`params` 与 `stack`；`stack` 是业务返回栈快照。
- 初始化与 `popstate` 仅恢复合法且同端的快照；状态缺失、跨端或未知路由时安全回退首页。
- `goBack()` 仅请求浏览器返回；实际路由、页面渲染和返回栈更新均由随后的 `popstate` 完成，避免重复回调。
- 本模块不负责 URL 深链或查询参数路由；地址栏路径仍不表达内部页面状态。

## 回归测试

- `src/js/router-history.test.js`：PC 与移动端的快照恢复、浏览器返回协调及无效状态回退。
- `src/js/pc-app-nav-motion.test.js`：PC 应用按恢复标签页启动时的导航当前态。
- `src/js/pc-utils.test.js`：PC 上下文菜单的层级键盘导航、分隔线、焦点归还与定位回归。
- `src/js/mobile-app-action-sheet.test.js`：移动端动作表的二级入口、返回路径和子级动作执行顺序。

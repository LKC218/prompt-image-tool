# 路由与启动模块

## 职责

本模块负责按运行环境选择 PC 或移动端应用，并在单页应用会话内协调页面切换、浏览器 History 状态与启动恢复。开屏（splash）负责首屏品牌亮相，并与应用挂载完成后的隐藏时机对齐。

## 源码入口

- `src/index.html`：开屏结构与内联样式；`#splashPixelCanvas` 像素溶解动画脚本暴露 `window.__splashPlay()`（Promise），完成后给 Logo / 标题加 `splash-icon-ready` / `splash-title-ready`。
- `src/js/main.js`：根据 `?ui=pc`、`?ui=mobile`、容器和视口条件加载对应应用；挂载完成后 `await splashPlay` 再对 `#splashScreen` 加 `splash-hide` 并移除节点。
- `src/js/pc/pc-app.js` / `src/js/mobile/mobile-app.js`：注册页面、挂载应用壳，并按路由器恢复的首个路由创建页面与同步导航状态。
- `src/js/pc/pc-utils.js` / `src/js/mobile/mobile-app.js`：提供跨页面动作菜单能力。PC 使用最多两层的级联上下文菜单，移动端将含 `children` 的动作项渲染为带返回入口的分层动作表。
- `src/js/pc/pc-router.js` / `src/js/mobile/mobile-router.js`：维护内存路由、业务返回栈与浏览器 History 快照。

## History 契约

侧栏更多菜单初始化时移至应用壳直接子节点，单独绑定原有导航处理函数；红点监听从菜单取节点。菜单按按钮位置固定定位，窗口缩放和侧栏宽度变化重新定位；外部点击、Esc 和路由切换关闭，Esc 归还按钮焦点。菜单打开期间保持侧栏展开，不能把移入外置菜单误判为离开交互区域。回归入口：`src/js/pc/pc-app-nav-motion.test.js` 和 `scripts/verify-sidebar-more-menu.mjs`。

## 悬停侧栏契约

导航按钮点击反馈仍由应用壳 `playNavIconClickMotion` 管理，不等待动画便执行路由或菜单操作。再次按下清理旧回弹，重复点击重新播放，不排队；只有目标图标的 `animationend` 可以结束点击态，伪元素扫光提前结束不截断回弹。450ms 兜底清理覆盖动画被取消或结束事件缺失，正常结束和重复启动都会清除旧计时器。相关回归位于 `src/js/pc/pc-app-nav-motion.test.js`。

`src/js/pc/pc-sidebar.js` 通过 `setupSidebarHover(root, { onStateChange, onLayoutChange })` 管理瞬时状态，应用壳提供状态写入与菜单定位回调。模块不依赖路由、存储或业务页面。应用重新挂载时调用返回的清理函数，释放计时器、事件监听、菜单观察器和尺寸观察器。

- 有悬停能力时默认收起；移入立即展开，移出延迟 150ms 收起，重新移入取消待收起任务。
- 不读写旧的 `pc-sidebar-collapsed` 存储键；旧值可以保留但不再影响 UI。
- 键盘焦点在侧栏或可见菜单内时保持展开；鼠标点击残留焦点不应锁住展开状态。
- 菜单打开时保持展开，通过菜单的 `hidden` 状态观察与侧栏解耦。
- `(hover: none)` 设备常展开，不增加触屏专属收展按钮；移动端应用不使用此模块。
- 不依赖动画结束事件解锁；CSS 过渡可随状态变化中途反向。单元测试为 `src/js/pc/pc-sidebar.test.js`。
- 控制器仅在真实的展开到收起变化时添加 `pc-sidebar-collapse-feedback`，首屏和重复状态同步不重播；重新展开或卸载移除，减少动态效果时不添加。该类只控制 CSS 单次图标落定，没有新增延迟状态提交或业务依赖。视觉回归为 `scripts/verify-sidebar-collapse.mjs`。

PC 内部路由 `/compress` 懒加载 `pc-compress.js`，侧栏位于「新建/编辑」之后、「目标计划」正上方。卸载时中止请求、发送取消、撤销对象地址并清空队列；不写图库或恢复批次。移动端不注册该路由。详见 [图片处理模块](./图片处理模块.md)。

- 每个同端 History 条目包含 `view`、`path`、`params` 与 `stack`；`stack` 是业务返回栈快照。
- 初始化与 `popstate` 仅恢复合法且同端的快照；状态缺失、跨端或未知路由时安全回退首页。
- `goBack()` 仅请求浏览器返回；实际路由、页面渲染和返回栈更新均由随后的 `popstate` 完成，避免重复回调。
- 本模块不负责 URL 深链或查询参数路由；地址栏路径仍不表达内部页面状态。

## 开屏像素动画

- 全屏画布铺满 splash；从 `./assets/icons/图标.svg` 采样为 `24×24` 色块，自视口四边/四角边缘飞入，在约 `2.2s` 内向中心 `64px` Logo 网格聚合；粒子错峰 `0–520ms` 入场。
- 聚合完成后交叉淡入清晰图标（`scale 0.94 → 1` 回弹）与标题。
- 计时使用 `performance.now()` 差值 + `requestAnimationFrame`，禁止 `sleep` 累计；画布按 `devicePixelRatio`（上限 2）缩放。
- `prefers-reduced-motion: reduce` 或图片失败时直接静态展示 Logo / 标题，并立刻 resolve `__splashPlay`。
- 开屏样式仍内联在 `src/index.html`，属于主 Token 链例外，需纳入首屏验收。

- `src/js/goal/goal-utils.test.js`：任务右键菜单分组顺序与 `divider` 插入位置。

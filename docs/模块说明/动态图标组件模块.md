# 动态图标组件模块

## 职责

该模块提供可独立试用的 React 动态图标组件，目前包含 `AudioLines`。组件仅负责 SVG 图标渲染和 Motion 动画，不接管主应用页面、路由或业务状态。

## 源码

- `src/react/icons/audio-lines.jsx`：`AudioLines` React 组件。
- `src/react/icons/audio-lines.css`：图标基础样式与减少动效兼容。
- `src/react/icons/audio-lines-demo.jsx`：本地演示页面交互。
- `src/react/icons/audio-lines-demo.html`：Vite 多页面演示入口。
- `src/react/icons/mount-animated-icons.js`：原生 DOM 到 React 图标的挂载适配层，管理 React root 生命周期。

## 使用

```jsx
<AudioLines active={isPlaying} size={28} label="音频播放中" />
```

`active` 控制循环动画，`animateOnHover` 和 `animateOnTap` 用于交互触发，`reducedMotion` 用于业务侧主动关闭动画。组件默认响应系统的 `prefers-reduced-motion` 之外，还可以由演示页或上层状态显式控制。

## 接入原生页面

在原生 JavaScript 页面中通过占位节点使用：

```html
<span data-react-icon="audio-lines"
      data-icon-size="16"
      data-icon-active="true"
      data-icon-hover="true"
      data-icon-label="语音输入"></span>
```

页面 `mount` 时调用 `mountAnimatedIcons(container)`，页面 `unmount` 时调用 `unmountAnimatedIcons(container)` 清理 React root。当前已在 `src/js/pc-editor.js` 正向提示词区域接入试点。

## 本地验证

- 启动 Vite 后访问 `/react/icons/audio-lines-demo.html`，可独立观察组件动画与状态控制。
- 进入 PC 端新建/编辑页，正向提示词标签旁会出现动态语音输入图标，点击后提示"语音输入功能开发中"。

图标表达的是状态动画，不是音频频谱可视化。

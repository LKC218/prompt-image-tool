# PC端提示词详情弹窗模块

## 职责

管理 PC 端提示词详情的多实例窗口、最小化入口、背景模糊、窗口焦点与详情页跳转收尾。

## 源码位置

- `src/js/pc-detail-modal.js`
- `src/js/pc-detail.js`

## 交互约束

- 最多同时展开两个详情窗口；重复打开同一提示词时激活已有窗口。
- 双窗口均保持不透明的实体详情表面；激活状态仅用于焦点、键盘操作与辅助语义，不能通过降低非激活窗口整体透明度来表达，避免与共享背景模糊层发生透叠。
- 最小化时正文先轻微上移淡出，窗口再向右下收束；右下角以单个摘要入口呈现最近最小化项和收纳数量。点击摘要入口展开可选择的收纳详情列表，点击指定条目恢复对应窗口，不能直接恢复最近一项。点击托盘外部或按 `Escape` 收起列表。恢复时按反向路径先还原窗口再显示正文。展开窗口期间锁定实际页面滚动容器 `#pcMain`，遮罩承接窗口外部指针与滚轮命中；所有窗口最小化后清除背景模糊并恢复原滚动状态，窗口正文保持独立滚动。
- 最小化、恢复期间阻止同一窗口的重复触发；低动效偏好下直接切换状态，跳过补间动画。
- 弹窗内点击编辑时，详情模块调用实例级 `onEdit` 回调，弹窗层最小化全部展开详情窗口后再跳转编辑页，保留详情状态且避免窗口覆盖编辑页面。
- 独立详情页未提供 `onEdit` 回调，保持直接跳转编辑页的行为。

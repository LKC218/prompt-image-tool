# 首页挂机种植物模块

## 职责

在 PC 首页欢迎横幅（176px）内展示一株长期挂机植物：按**有效在线时长**逐步长叶，支持每日浇水/施肥/除害轻养护，用于可视化记录使用软件的时间。不占路由、不进侧栏、不推挤下方布局。

| 文件 | 职责 |

| `src/js/plant-core.js` | 纯逻辑：状态、tick 累计、换叶、阶段、养护、跨天、时间回拨、debug |

## 渲染策略

- **30 天日历轮回**：`cycleStartAt` → `cycleDay` 1–30，映射 12 档整图 `cycle/01-seed…12-dead`。
- **日变化**：按 day 固定 `tilt/scale/hue` + 露珠/瓢虫/蝴蝶/花/落叶装饰（确定性）。
- **交互**：浇水/施肥/除害只做反馈，**不加速生长**；day≥30 可「铲除 · 可重开」（弱确认），`totalCycles+1`。
- **天数徽章**：盆左下角 `N/30`，title 含本轮 `activeDays` 与历史轮数。
- **设置**：「数据备份与恢复」→「重置挂机植物」强制回第 1 天。
- **离线**：API 连续失败 ≥2 次，横幅小字「离线暂存本地」。
- **园艺光标**：植物区 CSS `cursor: url(fx/cursor-*.png)`，浇水/施肥/除害/铲除各用对应指针。
- 素材缺失时可回退旧 stage 图或 SVG。
- 生图对照：`docs/素材与提示词/首页挂机植物-30天轮回对照与生图提示词.md`。

## 存储

- 正式档：`localStorage['pc-plant-state']` **+** `DATA_DIR/plant.json`（双写）
- 调试配置：`localStorage['pc-plant-debug']`
- 调试植物档：`localStorage['pc-plant-debug-state']`（倍率≠1 / 跳叶时使用，与正式档隔离）

### 持久化（重装/更新不丢）

| 层 | 说明 |
|----|------|
| 文件 | `%APPDATA%\PromptImageManager\data\plant.json`（与 prompt_sets 同目录） |
| API | `GET /api/plant` · `POST /api/plant` |
| 启动 | API → localStorage 迁移 → 新建 |
| 养护/铲除 | 立即写 API + LS |
| 失败回退 | API 挂了仍写 LS，不阻塞首页 |
| 备份 | `export` JSON 含 `plant`；`import` 可恢复 |

## 关键规则

- 有效时长：窗口可见且聚焦才累计；后台不涨；单次 tick 上限 45s（防休眠灌入）。
- 换叶：约 20 分钟 / 叶；总上限 60；每日上限 6。
- 跨天：`rollDay` 先结算当日叶（含养护加成）再写入 `bankedLeafCount`，避免加成叶丢失。
- 养护全完成：当日时长换叶 ×1.15。
- 系统时间回拨：忽略该 tick，不倒扣。
- Debug：`?plantDev=1` 或 `window.__PC_PLANT_DEV__ = true`；加速/跳叶不污染正式档。

## 接入点

- `pc-home.js` `render` → `overlayHtml: <div id="pcPlantAnchor">`
- `mount` → `createPlantTracker` + `mountPlantView` + `start`
- `unmount` → `stop` + `destroyPlantView`

## 后续可替换

`plant-view` 与 `plant-core` 解耦；美术替换只需改 view 的绘制实现（SVG → PNG/皮肤），计数逻辑不变。

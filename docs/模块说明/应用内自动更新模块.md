# 应用内自动更新模块

## 职责

PC 生产包（PyInstaller）通过应用内检查 GitHub Releases 的 `latest.json`，完成新版本发现、下载、SHA256 校验与 NSIS 静默安装。

## 源码位置

| 文件 | 职责 |
| --- | --- |
| `python/auto_update.py` | 更新核心：拉元数据、比版本、下载校验、`/S` 安装 |
| `build/auto_update.py` | 生产侧同内容副本（PyInstaller 从 `build/` 打包） |
| `python/main.py` / `build/app_main.py` | HTTP 路由：`/api/update/check|download|install` |
| `src/js/auto-updater.js` | 前端封装与启动/手动检查流程 |
| `scripts/publish_release.ps1` | 发版时生成并上传 `latest.json` |

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/update/check?localVersion=` | 比对远程 `latest.json` |
| POST | `/api/update/download` | `{url, sha256}` 下载到临时目录并校验 |
| POST | `/api/update/install` | `{path}` 以 `/S` 启动安装器并退出应用 |

## 发布元数据

`releases/latest.json` 由发布脚本生成，字段：`version` / `pub_date` / `notes` / `platform` / `url` / `sha256`。

托管地址：`https://github.com/LKC218/prompt-image-tool/releases/latest/download/latest.json`

## 维护说明

- 修改 `python/auto_update.py` 后必须同步 `build/auto_update.py`。
- 发布后确认 Release 含 `latest.json`，且 `url` 指向本版本 Setup 包。
- 启动检查失败静默；「暂不」会跳过该远程版本（localStorage：`pc-update-skip-version`）。

# 应用内自动更新模块

## 职责

PC 生产包（**Tauri + Sidecar**，见 [PC发包规范-Tauri主路径](../构建方案/PC发包规范-Tauri主路径.md)）通过应用内检查 GitHub Releases 的 `latest.json`，完成新版本发现、下载、SHA256 校验与 NSIS 静默安装；安装器启动后由分离 helper 等待安装结束并自动拉起新版本。

## 源码位置

| 文件 | 职责 |
| --- | --- |
| `python/auto_update.py` | 更新核心：拉元数据、比版本、异步下载 Job（进度/取消）、校验、`/S` 安装、解析安装目录并分离启动重启 helper |
| `build/auto_update.py` | 生产侧同内容副本（随 `server.spec` Sidecar 打包） |
| `python/main.py` / `build/app_main.py` | HTTP 路由：`/api/update/check|download|progress|download/cancel|install` |
| `src/js/release/auto-updater.js` | 前端封装：检查 / 启动下载 / 轮询进度 / 取消 / 安装（携带 `expectedVersion`）；更新会话互斥；确认框文案「暂不更新 / 下载安装」；请求经 `resolveApiBase()` 拼绝对地址（Tauri 壳下页面源与 Sidecar 不同源） |
| `src/js/release/update-progress-modal.js` | 更新进度弹窗（紧凑步进器）：大号百分比、细进度条、垂直时间轴三阶段、字节/速度、取消/重试；样式去拟态（`05c-global-overlays.css`）；操作按钮按 mode 缓存不重建；installing/ready 不渲染操作钮 |
| `src/js/pc/pc-utils.js` | `showConfirmModal` 返回 Promise：确定 true，取消/Esc/遮罩/被覆盖 false |
| `src/js/pc/pc-app.js` | 侧栏常驻「检查更新」入口（更新记录旁） |
| `src/js/pc/pc-settings.js` | 设置页独立「软件更新」卡片 |
| `scripts/publish_release.ps1` | 发版时生成并上传 `latest.json` |

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/update/check?localVersion=` | 比对远程 `latest.json` |
| POST | `/api/update/download` | `{url, sha256}` 启动后台下载，立即返回 `{jobId}` |
| GET | `/api/update/progress?jobId=` | 查询阶段与进度：`pending/downloading/verifying/ready/failed/cancelled` |
| POST | `/api/update/download/cancel` | `{jobId}` 请求取消，chunk 循环内生效并清理临时文件 |
| POST | `/api/update/install` | `{path, expectedVersion?}` 以 `/S`（及 `/D=<安装目录>`）启动安装器，分离 helper 负责安装结束后自动重启；随后退出当前应用 |

### 安装后自动重启（Windows 生产包 / Tauri 主包）

1. `resolve_target_exe(install_dir)`：目录内按序探测 `生图提示词管理器.exe` → `PromptImageManager.exe`。
2. `resolve_install_dir()`：父进程（Tauri 主壳）exe 目录 → Sidecar 路径上溯（跳过 server 旁路）→ 注册表 `InstallDir` / Uninstall 项 → `%LOCALAPPDATA%\生图提示词管理器` 或 `PromptImageManager`。
3. `run_installer` **先** `Popen` `"<setup>" /S`（仅当安装根可信时追加末尾无引号 `/D=<install_dir>`），再分离启动 PowerShell helper；**禁止**在 Popen 前 `taskkill` 主程序（避免 Tauri `Exit` 连带杀掉 Sidecar）。
4. helper 等待安装器 PID 结束，Settle 默认 3s；`expectedVersion` 仅软校验日志，**不**因 meta 缺失/不一致拒绝启动；`Start-Process` 目标为已解析主 exe。
5. 安装请求成功后前端关闭 Tauri 主窗（`closeShellAfterInstall`），`RunEvent::Exit` 回收 Sidecar；后端仍有约 0.3s `os._exit` 兜底。开发环境/非 Windows 不启用 helper。
6. 诊断日志：`%TEMP%\prompt-image-update.log`。

## 发布元数据

`releases/latest.json` 由发布脚本生成，字段：`version` / `pub_date` / `notes` / `platform` / `url` / `sha256`。

托管地址：`https://github.com/LKC218/prompt-image-tool/releases/latest/download/latest.json`

## 维护说明

- 修改 `python/auto_update.py` 后必须同步 `build/auto_update.py`；修改 `python/main.py` 更新路由后同步 `build/app_main.py`。
- 发布后确认 Release 含 `latest.json`，且 `url` 指向本版本 Setup 包。
- 本地 `releases/` 维护：保留 `latest.json` + 当前最新 Setup 包即可；旧版与过期 notes 在 GitHub Release 上传后删除（见 [工程目录说明](../工程指南/工程目录说明.md)）。
- 启动检查失败静默；确认框「暂不更新」会跳过该远程版本（localStorage：`pc-update-skip-version`），手动检查会清除跳过。Esc / 点遮罩关闭等同取消，Promise 正常结算，不会卡住「检查更新」按钮。
- **Tauri 同源约束**：前端页面跑在 `tauri://` / `https://tauri.localhost`，Python Sidecar 在 `http://localhost:8888+`。所有 `/api/update/*` 必须经 `resolveApiBase()` 拼绝对地址，禁止裸相对路径 `fetch('/api/...')`。设置页网络信息兜底请求同理。
- 设置页「软件更新」卡片的状态提示按检查结果显示：`已是最新 v…` / `可更新到 v…` / `检查失败`，不再只显示「已检查」。
- 同一时刻仅允许一个更新会话（确认→下载→安装）；并发进入直接返回 `busy`。
- Windows 静默安装命令行手工拼接 `"<setup>" /S /D=<dir>`：`/D=` 必须末尾且不带引号（NSIS 限制，路径含空格也如此）。仅当安装根可信（存在且非 server 旁路）才追加 `/D=`。
- 主 exe 候选：`生图提示词管理器.exe`（Tauri 主包）→ `PromptImageManager.exe`（应急 PyInstaller）。
- 入口：侧栏底栏横排（更新记录 / 检查更新 / 主题 / 设置）+ 设置页「软件更新」卡片。
- 确认更新后打开阶段式进度弹窗（下载/校验/启动安装/自动重启）；下载中可取消，失败可重试。轮询间隔约 250ms。
- 网络加固：检查更新对每个候选 URL 最多重试 3 次；直连 GitHub 失败后回退 `ghproxy.net` / jsDelivr（`@main/releases/latest.json`）。安装包下载在 GitHub 直连失败时自动尝试 `ghproxy.net` 前缀镜像。SSL/EOF 中断会转成可读中文错误。
- helper 启动失败不阻断安装；`expectedVersion` 仅软校验（Tauri 无 `frontend/index.html`），目标 exe 存在即尝试启动。
- **安装/卸载前清进程**：NSIS `NSIS_HOOK_PREINSTALL` / `NSIS_HOOK_PREUNINSTALL`（`src-tauri/nsis/installer-hooks.nsh`）结束 `生图提示词管理器.exe`、`PromptImageManager.exe`、`PromptImageManager-Server.exe`（`/T` 杀树）以及命令行归属本项目的 `python.exe`。应急壳 `build/installer.nsi` 安装/卸载节使用同一宏。
- **退出回收**：Tauri `Exit` 对 Sidecar `kill+wait`，并 `taskkill /PID /T /F` 杀树，再按镜像名兜底。`run_installer` **不**在 Setup 启动前结束主程序；主窗由前端 `closeShellAfterInstall` 关闭，Sidecar 由 Exit / 后端 timer 回收，清进程留给 NSIS hook。

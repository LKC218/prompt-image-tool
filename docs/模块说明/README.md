# 模块说明

就近模块文档：职责、相关文件、交互边界。**功能改动后优先同步这里**。

## 放什么 / 不放什么

- **放**：单模块是干什么的、代码在哪、关键行为与数据。
- **不放**：完整平台架构（→ 技术文档）、发版内容（→ 版本记录）、页面视觉稿（→ 页面与UI）。

## 同步约定

1. 新增/重构模块时，在本目录增加短文档，并登记到 [导航/apps-code-map](../导航/apps-code-map.md)。
2. 模块文档只写「职责 + 文件 + 边界」，细节链路写技术文档或代码注释。
3. 与 compose 规格（[计划与规格/compose-spec](../计划与规格/compose-spec/)）交叉时，实现以代码与模块说明为准。

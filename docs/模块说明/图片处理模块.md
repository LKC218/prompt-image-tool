# 图片处理模块

## 范围与入口

PC 侧栏「图片处理」复用 `/compress` 批量工作台，支持 PNG、JPEG、静态 WebP 的混合导入、压缩优化、格式转换和自定义尺寸。不覆盖原图，不读写图库，不接入同步或移动端。不支持动画、裁剪、补边、水印和固定文件体积。

## 处理契约

| 模式 | 实现 | 安全边界 |
| --- | --- | --- |
| PNG 原格式优化 | Oxipng 10.2.1 + PyPNG | 始终无损，保留位深、透明像素及全部非 IDAT 块；详见 PNG 专项说明 |
| JPEG 原格式无损优化 | jpegoptim 1.5.6 | 不传质量参数；比较解码像素及全部 APP、COM 标记，变化则退回原图 |
| WebP 原格式无损优化 | Pillow 12.3.0 / libwebp | `lossless=True, exact=True`；像素及非图像元数据块比较，变化则退回原图 |
| JPEG／WebP 有损优化 | Pillow | 用户明确选择有损与质量 1–100；同格式无体积收益则保留原图 |
| PNG／JPEG／WebP 转换 | Pillow | JPEG 必须有损且填充透明区域；PNG 与无损 WebP 比较解码 RGBA；结果可能增大 |
| 实际尺寸调整，可叠加转换 | Pillow Lanczos | 按显示方向逐图计算；JPEG 按质量重编码，不调用 jpegoptim；PNG 无损编码不等于无损缩放；结果增大也不回退原图 |

转换不恢复已有 JPEG／WebP 丢失的细节。高位深 PNG 只允许原格式优化；特殊颜色模式（如 CMYK）不自动转换，JPEG 原格式无损仍可用。拒绝 APNG、动画 WebP、超限、损坏及不支持的输入；实际格式由内容识别，不依赖扩展名。

转换／有损／尺寸调整需勾选元数据提示。未缩放转换尽力传递 ICC、EXIF、XMP、文本，但不宣称跨格式保留全部元数据；实际缩放只归正一次方向，不嵌入可能过时的 EXIF/XMP（含方向、尺寸与缩略图），保留原始快照并明确报告。ICC 与可支持文本尽力保留。ZIP 同时提供 `.metadata.json`，含原始非图像元数据块 Base64、源格式、尺寸、处理提示。它不是原图备份或自动恢复工具。导出内容可能含 EXIF 定位或提示词等隐私，请自行确认分享范围。未缩放的无损优化仅导出图像；实际缩放／有损／转换单图下载也使用 ZIP，避免遗漏报告。

## 页面交互

横幅直接复用 `pc-welcome-banner.js`。主区只展示队列与结果；可折叠「处理设置」包含模式、目标、编码、按需质量与 JPEG 填充色、计算等级及高级设置。缩略图仅预览填充色，不是最终有损编码预览。PNG 线程 1–4、预算 15／30／60 秒仅用于 Oxipng；等级 0–6 用于 PNG／WebP 计算尝试，JPEG 忽略。默认原格式无损。

切换参数不覆盖已有结果；「重新处理所选」释放旧结果并重新排队，未导出时确认。错误不阻断其他任务，可重试失败项。文件名追加「压缩」或「转换」，扩展名按实际结果生成，保留安全相对路径与去重。

### 设置的信息层级

- 常用区保留模式、输出格式、有效编码／质量、尺寸和优化预设。PNG 输出及 JPEG 转换使用固定编码状态行；可选编码仍用分段按钮。质量按输出格式与所选批次展示，仅选 PNG 时不显示 JPEG 缩放质量；只处理 JPEG 时隐藏无效的优化强度。
- `syncRelevantSettings` 只更新显隐，不重建控件或改写现有参数。导入、选择、移除与参数变化均刷新展示；折叠、格式切换不丢失高级设置。混合批次的实际编码规则不变。
- 宽高双列保持，比例锁并入高度标签行，用 aria-pressed 与短文字呈现；拉伸风险与非法值仍在控件旁提示。“仅缩小”默认勾选，规则不变。
- 默认只显示四档优化预设；精确等级、PNG 线程／预算、缓存维护及恢复默认放在一个默认折叠的 `#imageAdvanced`。非预设等级显示“自定义 N”，避免折叠后不知道生效值。
- 风险确认缩短为“我了解像素及元数据可能变化”，完整说明位于相邻的 `#imageRiskDetails`；展开详情不自动勾选，不降低开始处理的确认门槛。完整说明包含缩放改变像素、JPEG 重编码、元数据快照与隐私、体积及容量边界。
- 保留 285px 固定内宽、标题固定与独立滚动；不通过减小字体压缩信息。验收脚本 `scripts/verify-image-settings-density.mjs`，单测 `src/js/pc/pc-compress.test.js`；前后高度实测与边界见 [设置精简验收记录](../质量与复盘/图片处理设置精简-验收记录-261007.md)。

### 尺寸规则

- 独立开关默认关闭；开启后默认锁定比例、仅缩小，不预先编码。字段在编码设置之后、优化等级之前，按模式展示。
- 指定尺寸：锁比例时可只填一边，另一边按每张图推导；双边视为最大边界，等比放入，不裁剪。解锁必须填两边，精确输出并提示可能拉伸；仅缩小时分别限制两轴不超过源图。
- 百分比：25%／50%／75% 快捷项和精确输入。最长边：逐图识别横竖方向，适合混合批次。
- 输入宽高按 EXIF 显示方向，交换方向 5–8 的宽高；非缩放路径不更改原文件方向契约。正数取 `floor(x + 0.5)`，至少 1 像素。
- 参数边长 1–16384 整数，百分比 0.01–1000、最多两位小数；输入与最终输出不超过 1600 万像素，实际编码结果不超过 32 MiB。未启用时忽略遗留尺寸字段。
- 参数格式错误禁止开始；逐图超限或不支持的位深／颜色模式在行内提示并失败，不阻断其他图片。高位深 PNG、CMYK 等首版不自动降位深／转色，即使仅缩小计算为原尺寸也保守拒绝尺寸模式。
- 合法且无需实际缩放时走原优化／转换路径；实际缩放绕过无损引擎和体积回退，保持透明，仅 JPEG 填充背景。JPEG 缩放明确使用质量 1–100，默认 85。
- 文件名下显示原始尺寸→预计尺寸，已有结果另标「已生成」实际尺寸；调参后标记「旧参数」。旧结果仍可导出，只有「重新处理所选」才释放并重新排队。
- 前端 `image-resize.js` 与后端 `image_resize.py` 是两端纯数学实现，共用 `tests/fixtures/image-resize-cases.json` 防止取整与边界漂移；不新增运行时网络或图库依赖。

## 缓存与容量

- 浏览器：最多 100 张，输入总计 100 MiB，单图 20 MiB、1600 万像素；结果及报告估算总计 100 MiB，ZIP 输入字节另校验 100 MiB。单个编码结果不超过 32 MiB。打包、解码和浏览器对象有额外内存开销，这些不是进程内存硬上限。
- 队列仅驻留当前页面；清空、移除、重新处理、离页释放对应引用和预览 URL。下载 URL 最长 30 秒撤销。刷新／离页不持久化结果，需先导出。
- 磁盘：`%TEMP%/PromptImageManager/image-tasks-v1/task-<随机标识>`，只存本次输入、中间候选及报告。正常、异常、取消均在 finally 回收。异常强杀可能遗留；首次进入状态查询及手动清理时，仅清理超过 24 小时、有专属 owner 标记、租约非活跃的直接任务子目录。
- 不递归扫描系统临时目录；跳过链接、联接、不明文件夹和非普通文件。UI 显示磁盘临时文件及可清理大小，不把前端结果缓存混为磁盘缓存。
- 一个后端进程只执行一个图片引擎任务；多格式上传在读入前限制并发。隔离进程墙钟上限 90 秒、前端请求 120 秒；取消杀死子进程并等待退出。旧 PNG 兼容入口沿用原有上传逻辑。

## API

所有入口仅本机地址、允许的本机 Origin／Host；POST 使用状态接口返回的 `X-Png-Token`。处理与上传不占业务数据全局锁。

| 路径 | 作用 |
| --- | --- |
| `GET /api/image-process/status` | 检查引擎、返回 ready、version、token、缓存统计并回收过期任务 |
| `POST /api/image-process/inspect` | 二进制图片识别与完整解码检查，返回 format、显示 width／height、storedWidth／storedHeight、orientation、depth、alpha、mode |
| `POST /api/image-process` | 原始二进制；查询参数 operation、target、encoding、quality、background、ack、level、threads、budget、job，以及下述尺寸参数 |
| `POST /api/image-process/cancel?job=<uuid>` | 请求取消，不等于任务已结束 |
| `POST /api/image-process/cache-clean` | 仅清理符合上述条件的过期任务 |

处理成功返回 `multipart/form-data`，`image` 为结果文件，`report` 为 JSON；状态包括 compressed、unchanged、preserved、converted。错误为 JSON，参数／处理失败 400、越权 403、上传繁忙 429。原 `/api/png-compress` 接口保留兼容。

尺寸参数：`resize=true|false`（默认 false）、`resizeMode=dimensions|percent|longest`、`width`、`height`、`percent`、`longest`、`lockRatio=true|false`、`onlyShrink=true|false`。布尔值严格校验；仅验证当前模式数字参数。启用尺寸需 `ack=true`。启用缩放或 Pillow 路径报告含 `output:{width,height}`（显示尺寸）、`resized`；旧 PNG 快捷路径无此字段时前端沿用已识别尺寸。实际缩放的元数据报告即使快照为空也随 ZIP 导出。

脚本用法见 [scripts/README.md](../../scripts/README.md)，本轮结果见 [多格式验收记录](../质量与复盘/图片多格式处理-验收记录-261007.md)。发布材料准备见 [第三方图片引擎分发说明](../构建方案/第三方图片引擎分发说明.md)；`verify_frozen_release.py` 单独验证真实冻结 Sidecar，不代替安装升级验收。

## 轻拟态控件与微交互

- 全页使用现有主题令牌：面板柔和外阴影、输入浅内凹、按钮按下内凹；列表本体保持平整，避免逐行浮雕。仅修改图片处理页，不等于全站 UI 改造。
- 自定义滑块轨道／手柄、复选框、分段选中块、进度条、图标按钮和颜色输入。颜色使用预设色与六位十六进制输入，不打开系统颜色弹窗；非法输入阻止 JPEG 转换。系统文件选择器不在应用样式控制范围内。
- 按钮反馈 140 毫秒，分段切换 200 毫秒，面板与工作区联动展开 260／收起 220 毫秒。仅新增小批量行执行入场，超过 12 行不逐项播放；删除行先禁用交互再短暂退出。
- 列表按任务 ID 复用节点，只同步属性和文本；状态变化才触发完成反馈，不通过整表 innerHTML 重建打断焦点或重载缩略图。
- 重新处理使用原生 dialog 语义与自定义轻拟态外观；默认聚焦取消，支持 Escape 和浏览器焦点约束。取消弹窗不同时关闭设置面板。原生 window.confirm 已移除。
- 页内单条通知复用，不堆叠；离页清理通知计时器、动画与弹窗。面板收展采用可反向 CSS 过渡，不依赖异步完成回调。
- CSS 与 Web Animations 均遵循减少动态效果偏好。真实任务数驱动进度，忙碌指示不伪造百分比。没有新增动画依赖或后台处理耦合。
- 验证：`scripts/verify-image-interactions.mjs`，截图与结果写入被忽略的 `output/image-interactions/`。

### 设置面板收展

宽屏通过局部 grid 列占位在 0 与 305px 间过渡，参数面板始终保持 285px，不缩放文本或控件。为真实让位采用局部布局插值，而非仅平移面板；不承诺低端设备帧率。窄屏保持主区宽度，面板覆盖滑入，禁用列宽过渡。标题与关闭按钮不滚动，参数放在独立滚动容器 `.image-settings-scroll`，收起不销毁节点，保留滚动位置。

入口按钮固定宽度，展开时内凹并翻转方向箭头。关闭立即设置 inert 与 aria-hidden，视觉退出后 visibility 隐藏；快速反向由 CSS 从当前插值继续。减少动态效果时直接切换。验证脚本为 `scripts/verify-image-panel-motion.mjs`，保存真实布局中间帧数据，而非仅检查最终显示状态。

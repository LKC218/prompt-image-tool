# 摸鱼时间游戏中心模块

## 职责

PC 侧栏「摸鱼时间」提供游戏选择中心：卡片展示各游戏简介，确认后进入。当前内置俄罗斯方块与飞机大战。不接入业务存储。

## 源码位置

| 文件 | 职责 |
| --- | --- |
| `src/js/pc-games-hub.js` | 中心页卡片、简述、确认进入 |
| `src/js/pc-tetris.js` / `tetris-core.js` | 俄罗斯方块 |
| `src/js/pc-plane.js` / `plane-war-core.js` | 飞机大战 |
| `src/assets/pc/games/plane/` | 飞机大战贴图：player / enemy-basic / enemy-fast / enemy-heavy / bullet-player / bullet-enemy / fx-explosion / fx-thruster |
| `src/css/pc/09-tetris.css` / `10-plane.css` | 游戏页与中心样式 |
| `src/assets/pc/nav-icons/games.png` | 侧栏手柄图标 |
| `src/js/pc-app.js` | `/games` 导航；`/tetris`、`/plane` 高亮摸鱼时间 |

## 路由

| 路径 | 页面 |
| --- | --- |
| `/games` | 游戏中心 |
| `/tetris` | 俄罗斯方块 |
| `/plane` | 飞机大战 |

## 交互

- 卡片或「进入游戏」→ `showConfirmModal` 显示标题与简述 → 确认后 `navigate`。
- 飞机大战：鼠标/触控在战场滑动跟随（限底部活动区），按住或点击射击；键盘 ←→/↑↓ 移动，Space（及自动连射）射击，P/Esc 暂停，R 重开；最高分 `pc-plane-highscore`。

# 产品官网模块

## 职责

`website/` 是独立的产品介绍网页，面向尚未安装软件的访问者。它不参与 PC、Android 和主应用 Web 构建，不注册主应用路由，不修改应用存储。

## 文件导航

| 文件 | 职责 |
| --- | --- |
| `website/index.html` | 中文语义内容、首屏、五类功能展示、创作流程、FAQ、平台下载与图片预览对话框 |
| `website/src/style.css` | 暖白浅蓝主题、错落网格、响应式与减少动态效果 |
| `website/src/main.js` | 公开图片与版本绑定、进入视口动效、导航、对话框、异步加载三维模块 |
| `website/src/studio.js` | 原创程序化工作室、按需渲染、输入跟随、WebGL 降级与资源释放 |
| `website/vite.config.js` | 官网独立构建和相对资源路径 |
| `website/tests/website.test.mjs` | 结构、内容边界、可访问语义及构建资源静态回归 |
| `scripts/verify-website.mjs` | 本地 HTTP 与构建白名单验证，不替代浏览器验收 |
| `website/README.md` | 启动、构建、依赖、范围和交付边界 |

## 交互与无障碍

主导航与功能标题使用真实页内锚点。移动导航用 `aria-expanded` 表达状态，Esc 关闭后归还焦点。图片预览使用原生 `dialog`，关闭后解除背景滚动锁定并归还焦点。FAQ 使用原生 `details`。页面允许缩放，不限制用户最大缩放比例。

系统 `prefers-reduced-motion` 优先于手动动画设置。三维旋转使用绝对时间差阻尼，不按帧累计计时。场景静止、离屏或页面隐藏时不持续渲染；WebGL 不可用或上下文丢失时展示公开截图。桌面鼠标跟随属于装饰性交互，不阻挡正文、下载或移动端纵向滚动。

工作室保留 WebGL 最后一帧缓冲；尺寸变更后立即绘制一帧，输入时根据当前矩形复核可见性，避免整页截图临时视口变化与离屏暂停叠加后出现空白。截图验证必须检查画面确实包含模型，仅判断截图存在或哈希变化不代表三维验收通过。

## 跨模块依赖与风险

仅有构建时只读依赖：根目录 `package.json` 的版本，以及 `docs/assets/readme/` 的公开图片。没有运行时跨模块耦合，也不连接 `python/`、局域网同步接口或真实数据目录。测试复用根项目的 `jsdom`。

独立官网的 `dist/`、`node_modules/`、私有配置均被 `website/.gitignore` 排除；验收输出使用根 `.gitignore` 已覆盖的 `output/website/`。未来若单独拆仓，将版本与公开资源改成发布输入即可，不应为官网创建读取个人数据的接口。

平台、无损和同步边界：目标计划、对比阅读及图片处理标明 PC；Android 安装包以发布附件为准；缩放和 JPEG 重编码不宣传为无损；局域网同步不宣传为公网云同步。没有在线账户、联系表单、订阅或支付流程。

# 目标计划模块

## 职责

按「项目 → 任务」两级结构管理创作/工作清单：项目作为容器，任务支持父子层级、完成状态联动、图片附件与优先级标记。

## 源码位置

- `src/js/pc/pc-goal-projects.js`：PC 项目列表页。
- `src/js/pc/pc-goal-detail.js`：PC 任务详情/编辑页。
- `src/js/goal/goal-utils.js`：任务树状态计算、优先级常量、任务右键菜单分组数据（`buildTaskContextMenuItems`）、图片导入辅助函数，以及 `formatBytes()` 存储大小格式化。
- `src/js/goal/goal-image-preview.js`：任务图片小图标、悬浮预览与全屏查看。
- `src/css/pc/08-goal-plan.css`：PC 端目标计划全部样式。
- `src/js/core/sqlite-storage.js`：SQLite 数据持久化。
- `src/js/core/api-storage.js`：远程 API 存储接口。

## 数据模型

### 项目（project）

```js
{
    id,
    name,
    coverImage,   // 相对路径，空字符串表示无封面
    coverColor,   // 预留：自定义封面主色
    order,
    createdAt,
    updatedAt,
    taskCount,
    completedCount,
    progress,
    imageCount,   // 项目下图片文件数（含封面与任务图片）
    imageBytes    // 项目下图片总字节数，由存储层遍历 goal_images/<projectId>/ 实时计算
}
```

### 任务（task）

```js
{
    id,
    projectId,
    parentId,
    title,
    completed,
    order,
    priority,      // '' | 'high' | 'medium' | 'low'
    status,        // '' | 'executing'
    images: [],
    children: []
}
```

### 任务图片（image）

```js
{
    id,
    path,   // 相对路径，Capacitor 环境下为 Data 目录相对路径
    name
}
```

## 数据库存储

表 `goal_projects` 字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | TEXT | 主键 |
| `name` | TEXT | 项目名称 |
| `cover_image` | TEXT | 封面图相对路径，空字符串表示无封面 |
| `cover_color` | TEXT | 预留：自定义封面主色 |
| `sort_order` | INTEGER | 项目排序 |
| `created_at` | TEXT | ISO 时间 |
| `updated_at` | TEXT | ISO 时间 |

表 `goal_tasks` 字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | TEXT | 主键 |
| `project_id` | TEXT | 所属项目 |
| `parent_id` | TEXT | 父任务 ID，空字符串表示根任务 |
| `title` | TEXT | 任务标题 |
| `completed` | INTEGER | 0/1 |
| `sort_order` | INTEGER | 同级排序 |
| `priority` | TEXT | `high` / `medium` / `low` / `''` |
| `status` | TEXT | `executing` / `''` |
| `created_at` | TEXT | ISO 时间 |
| `updated_at` | TEXT | ISO 时间 |

图片独立存储在 `goal_task_images(path, name)`，通过 `task_id` 关联。

## 优先级标记

- 优先级字段 `priority` 为可选标记，空字符串表示无优先级。
- 内置三档：
  - `high`：红色 `#EF4444`
  - `medium`：橙色 `#F59E0B`
  - `low`：蓝色 `#3B82F6`
- PC 端在任务行首（拖拽把手左侧）渲染 8px 圆点，无优先级时保留占位空间以维持对齐。
- 设置入口：任务行右侧「更多」→「设置优先级」→选择档位/取消。
- 任务右键/更多菜单按功能分组并用与提示词菜单一致的细线分隔：状态（完成/执行中）→ 结构编辑（子任务/重命名/复制）→ 资源与定位（优先级/图片/定位）→ 危险（删除）。菜单数据由 `goal-utils.js` 的 `buildTaskContextMenuItems()` 组装，图标在 `pc-goal-detail.js` 注入。
- 已完成任务的优先级点自动降低透明度，避免干扰完成态。

## 执行中标记

- 任务字段 `status` 为 `'executing'` 时表示当前正在执行。
- PC 端在任务行左侧显示 3px 绿色垂直状态条，并伴随呼吸光晕动画。
- 设置入口：任务行右侧「更多」→「标记为执行中」/「取消执行中」。
- 任务被勾选完成时，自动清除 `status`，避免已完成任务仍显示执行中。
- 动画遵循 `prefers-reduced-motion`：系统开启减少动态效果时，只保留静态绿条，停止呼吸动画。

## 关键交互

- 项目卡片：PC 端项目列表以响应式网格展示，卡片采用「16:9 封面图 + 信息区」竖向布局；无封面时根据项目名称生成首字母渐变封面。hover 卡片轻微上浮，封面图轻微放大。卡片元信息行显示「N 个任务 · 存储大小 · 更新日期」，其中存储大小由存储层遍历 `goal_images/<projectId>/` 实时计算并经由 `goal-utils.js` 的 `formatBytes()` 格式化为 B/KB/MB/GB。
- 项目名称滚动：名称超长时不再截断省略，改以「外层裁切 + 内层 `span` 平移」的往返滚动展示（复用提示词库 `pc-library-name-scroll` 模式）；JS 侧 `setupProjectNameMarquee()` 按实际溢出距离计算时长（8-14s）与错峰延迟，悬停/键盘聚焦暂停，`prefers-reduced-motion` 下关闭动画并保留 `title` 悬停提示兜底。
- 项目封面：通过项目卡片「更多」→「设置封面」导入本地图片；仅接受 jpeg/png/webp 且不超过 15MB。PC 端经 `goal-utils.js` 的 `importGoalProjectCover` 导入：内部经 `optimizeGoalCoverDataUrl`（复用 `optimizeImageDataUrl`）Canvas 压缩为 WebP（质量 0.85、最大边 1600px）；优化失败或压后变大时回退原图，不阻断设置。落盘扩展名与实际内容 MIME 对齐（通常为 `.webp`）。随后经 `uploadGoalImage` 保存到 `goal_images/<projectId>/`，封面路径写入 `project.coverImage` 并由后端 `updateGoalProject` 持久化。任务更新/删除触发的图片清理会把 `coverImage` 并入 keep 列表，避免误删；`cover` 子目录跳过清理。封面加载失败时前端回退为首字母渐变封面。
- 项目排序：「我的项目」标题行右侧排序按钮弹出菜单，支持默认顺序 / 按名称 / 按创建时间 / 按更新时间 / 按进度 / 按存储大小。仅前端重排显示，不改写数据库 `sort_order`；偏好存 `localStorage`（key：`pc-goal-project-sort`），刷新后保持。当前排序项在菜单中以对勾图标标记。
- 复选框：叶子任务切换自身状态；父任务级联切换所有后代，并向上同步父任务完成状态。
- 完成自动沉底：完成状态变更后，`pc-goal-detail.js` 调用 `goal-utils.js` 的 `sortTasksByCompletion()` 对同级任务重新排序。未完成任务在前、已完成任务在后；同组内保持原有 `order` 相对顺序，递归处理各级子任务并更新 `order`。取消勾选时任务回到未完成组末尾。拖拽排序仍可在当前分组内调整顺序，下次完成状态变更时自动排序会再次生效。
- 拖拽调级：仅通过左侧 `grip-vertical` 把手触发；根任务与各级子任务容器共享 SortableJS group。落点语义为上 28% 插到上方 / 下 28% 插到下方 / 中部成子级 / 空白成顶层；悬停有落点提示，目标折叠时短暂悬停可自动展开。禁止父任务拖入自身子树。思维导图节点同样支持拖拽改层级（中部成子级、上下 30% 插兄弟、空白/根成顶层）。导图落点反馈：节点内侧条标插上/下、描边成子级；空白/根为 stage 内侧 accent 描边 + 光标旁 `drop-hint` 文案（「放到空白处成为顶层」）；`stage::after` 仅用于四边羽化，禁止再挂文案。拖拽中节点 `transition:none` 保证跟手；`pointerup/pointercancel` 在 window 兜底清理落点提示。
- 折叠/展开：父任务左侧箭头控制，折叠时显示子任务数量徽章。
- 图片：任务图片以悬浮小图标展示，hover 出浮窗，点击可全屏查看；「图片管理」弹窗支持粘贴导入（截图后 `Ctrl+V`），且文件/粘贴导入均会经 Canvas 压缩为 WebP（默认质量 0.85、最大边 1920px）后再持久化。
- 图片管理弹窗性能：网格按批渲染（首屏 20 张，滚动到底部 sentinel 后经 IntersectionObserver 追加下一批）；每张图片项初始仅携带 `data-src`，进入视口（预载 200px）后由 `goal-utils.js` 的 `getGoalThumbUrl()` 异步生成 320px 宽 WebP 缩略图（质量 0.75，Blob URL，模块级缓存）并替换 `src`；点击查看大图仍使用原图 URL。页面卸载时调用 `releaseGoalThumbUrls()` 释放全部 Blob URL。样式上图片项以 `aspect-ratio` 骨架占位并在 `[src]` 存在后淡入，避免布局抖动。
- 文本选中：PC 端项目卡片与任务行均设置 `user-select: none`，避免鼠标拖拽时误选名称、元信息等文字；卡片点击跳转与按钮交互不受影响。

## 扩展约束

- 新增任务字段时，需要同步更新：
  1. 内存任务对象的初始化（`pc-goal-detail.js` 的 `addTask` / `addChildTask`）。
  2. `sqlite-storage.js` 的建表语句、`ALTER TABLE` 迁移、`updateGoalTasks` / `_buildTaskTree` / `createGoalTask` / `updateGoalTask`。
  3. `goal-utils.js` 中如有序列化/反序列化特殊处理。
  4. 相关 UI 与样式。

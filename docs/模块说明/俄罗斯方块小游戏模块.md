# 俄罗斯方块小游戏模块

## 职责

PC 侧栏提供休闲俄罗斯方块入口与完整经典玩法：棋盘渲染、键盘/按钮操作、消行计分、等级加速、暂停/重开与本地最高分。不接入业务存储，不影响提示词与目标计划数据。

## 源码位置

| 文件 | 职责 |
| --- | --- |
| `src/js/games/tetris-core.js` | 纯逻辑：棋盘、7-bag、碰撞、旋转 kick、消行、计分、等级间隔 |
| `src/js/tetris-core.test.js` | 核心逻辑单元测试 |
| `src/js/pc/pc-tetris.js` | 页面壳：Canvas 绘制、输入绑定、rAF 下落循环、生命周期 |
| `src/css/pc/09-tetris.css` | 页面布局与新拟态控件样式 |
| `src/assets/pc/nav-icons/games.png` | 侧栏「摸鱼时间」mask 图标（方块页经中心进入） |
| `src/js/pc/pc-app.js` | `NAV_ITEMS` 增加 `/tetris`，`registerRoute`，`TAB_ROUTES` |
| `src/css/pc.css` | 引入 `09-tetris.css` |

## 路由与入口

- 路由：`/tetris`（仅 PC）；经侧栏「摸鱼时间」`/games` 中心卡片确认进入
- 侧栏主导航顺序：首页 → 提示词库 → 新建/编辑 → 目标计划 → 分类与标签 → **摸鱼时间**
- 页面导出约定：`render` / `mount` / `unmount`；`unmount` 取消 `requestAnimationFrame` 并解绑 `keydown`

## 操作

| 输入 | 行为 |
| --- | --- |
| ← / → | 水平移动 |
| ↑ | 顺时针旋转（简单墙踢） |
| ↓ | 软降（+1 分） |
| Space | 硬降（+距离×2） |
| P / Esc | 暂停/继续 |
| R | 重开 |

按钮区提供同等操作兜底；游戏结束遮罩内提供「重开」。

## 数据与计分

- 最高分：`localStorage` key `pc-tetris-highscore`
- 消行基础分：1/2/3/4 行 = 100/300/500/800，再乘当前等级
- 每消 10 行升 1 级；下落间隔 `max(100, 800 - (level-1)*70)` ms

## 维护说明

- 改规则请优先改 `games/tetris-core.js` 并补测；页面只做接线与绘制。
- 预览形状来自 `getShapeMatrix`，新增方块类型时只需更新 core 的 `SHAPES` / `PIECE_COLORS`。
- 移动端入口本次未做；若要做，复用 `games/tetris-core.js`，另建 `mobile-tetris.js` 与触控布局。

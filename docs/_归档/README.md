# 归档说明

本目录存放**已完成、过期或一次性**材料，不参与日常导航。

## 结构

| 子目录 | 内容 |
|--------|------|
| `计划/` | 已完成/已发布/无后续任务的实施计划（按原分类子目录保留） |
| `工程目录整理/` | 历史仓库与文档整理方案 |
| `对话历史/` | 重要构建与开发对话归档 |
| `设计过程/` | 会话交接摘要、早期版本设计过程稿 |

## 原则

1. 归档区**不是现行规范**；与活跃文档冲突时，以活跃文档为准。
2. 归档内部保留**迁移前的旧路径引用**，不强制批量改写历史正文。
3. 新增归档时：从活跃区 `git mv` 过来，并从对应索引中移除。
4. 若归档内容仍被活跃文档引用，请改为指向现行文档，而不是回迁归档文件。

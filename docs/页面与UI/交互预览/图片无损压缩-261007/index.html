这些预览可以做什么？
多选图片、导入文件夹、拖放文件、勾选与移除、切换主题及深色、模拟批量处理、导出演示报告。
边界：没有接入压缩引擎，不上传、不修改原文件。示例大小与所有压缩结果为演示值。文件夹导入能力由浏览器支持情况决定；三版队列相互独立。

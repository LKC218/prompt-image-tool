# 图片无损压缩交互预览

日期：2026-10-07。用途：方案评审，不属于主应用功能，不参与生产构建。

## 打开方式

直接用浏览器打开 [方案总览](index.html)，不需要安装依赖、启动业务后端或联网。请保留当前目录层级，预览复用仓库内主题令牌、字体及示例素材。

| 方案 | 入口 | 设计侧重点 |
| --- | --- | --- |
| 一 | [批量工作台](方案一-批量工作台.html) | 推荐；沿用侧栏，表格队列与设置并列 |
| 二 | [视觉画廊](方案二-视觉画廊.html) | 横向导航，大缩略图批量筛选 |
| 三 | [步骤向导](方案三-步骤向导.html) | 导入、设置、结果分步呈现 |

## 演示能力和边界

- 支持多文件选择、文件夹导入、文件拖放、勾选、移除、清空、恢复示例。
- 文件夹通过浏览器文件选择器导入；不承诺目录拖放递归读取。
- 最多 100 张、单张 20 MB；校验 PNG 文件签名，但不做完整图片合法性或 APNG 检测。
- 同一路径、大小、修改时间的文件在当前队列内去重；同名不同目录可共存。
- 浅深色及六套工作台主题，使用原项目主题令牌。
- 标准、深度均为模拟处理；按绝对时间差更新演示进度，可取消。
- 仅导出带明确声明的 JSON 演示报告，不导出所谓压缩图片。
- 示例名称与大小用于排版；所有结果体积均为模拟值，不代表真实收益。
- 所选本地文件仅以对象地址展示，移除、清空和退出时释放；不上传、不持久化、不更改源文件。
- 三版不共享队列；重新打开恢复示例。业务侧栏仅为视觉背景，无业务路由。
- 真实压缩、元数据保真、16 位保真、APNG 策略、安装包和移动端能力均未实现。

## 文件职责

- 三个方案 HTML：独立入口。
- `index.html`：选择导航。
- `预览样式.css`：共享轻拟态材质及三套不同布局。
- `预览交互.js`：本地文件队列、模拟状态和报告导出。
- `预览验证.mjs`：独立浏览器回归脚本；复用项目已有 Playwright，不自动安装依赖。执行：`node docs/页面与UI/交互预览/图片无损压缩-261007/预览验证.mjs`。
- `验收截图/`：本地验证截图，忽略入库。

## 设计约定

复用字体、语义表面、凸起及内凹阴影、品牌与状态令牌；深色不加入白色外发光。键盘焦点可见，状态不只依赖颜色，支持减少动态效果。方案确定前不修改运行时业务源码、不新增独立业务模块说明。

## 评审建议

优先选择布局，再确认是否组合：例如保留方案一的应用框架和批量表格，加入方案二的缩略图视图切换。真实压缩实现需另行确认。

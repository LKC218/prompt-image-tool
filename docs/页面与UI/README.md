# 页面与 UI

页面级 UI 方案、端侧布局设计与复刻稿。全局视觉 Token 与组件规范见 [设计系统](../设计系统/)。

## 结构

| 子目录 | 内容 |
|--------|------|
| `PC/` | PC 端页面 UI 计划（首页、库、详情、设置等）与安装器壳 UI 规则 |
| `移动端/` | 移动端页面 UI 计划与全局设计规范（页面级） |
| `复刻稿/` | 外部 UI 复刻设计文档（Uiverse、参考稿等） |
| `复刻稿/PC/` | PC 端精确复刻稿 |

## 放什么 / 不放什么

- **放**：单页布局、组件在页面中的用法、端侧交互稿、复刻对照。
- **不放**：全局主题 Token（→ 设计系统）、模块代码职责（→ 模块说明）、生图提示词（→ 素材与提示词）。

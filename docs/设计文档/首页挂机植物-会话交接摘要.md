## 2. 产品决策（已定稿）

| 项 | 结论 |
|----|------|
| 挂载点 | PC 首页 `pc-welcome-banner-home` 内 `overlayHtml`，高锁 176px |
| 生长驱动 | **真实日历 30 天**（非在线时长） |
| 轮回 | 生长 → 开花 → 凋落 → 铲除重开 |
| 养护 | 浇水/施肥/除害，每日 1 次；**只做反馈，不改 cycleDay** |
| 铲除 | `cycleDay >= 30` 才可；重置 `cycleStartAt` |
| 每天不同 | 12 档整图 + 按 day 的 tilt/scale/hue + 露珠/虫/蝶/花/落叶 |
| 不叠 leaf 精灵 | 方案 A：整图切换 + 淡入/呼吸/轻摇摆 |
| 美术 | GPT 镜面草扁平绘本风；可后续换皮 |
| Debug | Vite 本地默认打开；正式档与 debug 档隔离 |

**已废弃**：在线 20 分钟/叶、CARE_BONUS 加速、每日 6 叶上限、在 stage 整图上叠 leaf.png。

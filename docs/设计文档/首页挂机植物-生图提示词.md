# 首页挂机植物 · GPT 生图提示词

> 用途：为「提示词管家」首页横幅挂机种植物生成美术素材。  
> 分支：`feature/plant-idle-game`  
> 配套：`src/js/plant-view.js`（SVG 兜底）→ 后续可换 PNG 接入。

---

## 1. 选型建议

| 优先级 | 现实母本 | 拉丁名 | 说明 |
|--------|----------|--------|------|
| **A（推荐）** | 镜面草 / 圆叶椒草 | *Pilea peperomioides* | 圆叶干净、阶段感强，贴软 UI |
| B | 小琴叶榕 | *Ficus lyrata* | 剪影清楚，满级更有树感 |
| C | 多肉拼盘 | Echeveria 等 | 好画阶段，但「长高撑满」叙事弱 |

**默认按方案 A 出图。** 出图满意后再决定是否做 B/C 换皮。

---

## 2. 风格锁（每条提示词必带）

```text
扁平厚涂儿童绘本风，柔和马卡龙色，圆润造型，无写实阴影，
背景透明或纯浅蓝 #EAF3FF，居中单盆栽，无文字无水印，
与「云朵天际 + 柯基吉祥物」App 插画同一审美
```

- 建议尺寸：`1024×1024`（正方形，后续可裁）  
- 背景：优先透明底；否则纯色 `#EAF3FF`  
- 负面词见文末

---

## 3. 统一角色描述（每条阶段提示词都要前置拼接）

```text
同一株镜面草盆栽：陶土色圆润小花盆，浅色口沿，深色营养土，
茎细而挺，圆盘形叶片带短柄，叶片略厚、边缘圆滑，
主色 #6BC98A 到 #5BBF7A，茎 #4FA86B，盆 #E8B48A
```

---

## 4. 四阶段整图

### Stage 0 · 空盆 / 芽

```text
[统一角色] + 只有花盆和土面，土中央冒出 1 个极小的绿色芽点，
几乎贴着土面，构图极简，占画面下方 1/3，上方大量留白
```

### Stage 1 · 小苗（约 2–8 叶）

```text
[统一角色] + 短茎约画面高度 1/4，左右对生 3–5 片小圆叶，
叶片直径小于盆口，整体矮胖可爱，像刚买的迷你桌盆
```

### Stage 2 · 成长期（约 15–35 叶）

```text
[统一角色] + 茎长到画面高度 1/2，圆叶沿茎交替生长，
形成饱满圆形树冠，叶片疏密有致、有前后遮挡，
盆仍清晰可见，整体是健康茂盛的小盆栽
```

### Stage 3 · 满级 / 成树（撑满画幅）

```text
[统一角色] + 植株撑满画幅上下，茎更粗，圆叶密集成大冠幅，
顶部开出 1–2 朵极小的浅粉色花或星点高光，
底部陶盆只露出上半，整体像陪伴很久的「成年」桌面树，
氛围治愈、有成就感
```

## 5. 单叶精灵（「一片一片长」必需）

> 若只要阶段切换、不要逐叶生长，可跳过本节。  
> 要实现阶段内逐叶生长，**至少要有这一张**。

```text
单独一片镜面草圆叶，短柄朝左下，叶片朝右上，
扁平绘本风，主色 #6BC98A，描边 #3F9A62，
透明背景，居中，无盆无茎无文字无水印
```

可选补强（非必须）：

```text
同一片镜面草叶的三种大小：小 / 中 / 大，
透明底，风格完全一致，横向并排，便于做生长层次
```

## 8. 构图与工程约束（给生图时的人工检查项）

- [ ] 植株总高控制在画幅约 **85%** 以内，盆底可裁切对齐横幅底  
- [ ] 主绿偏灰绿，勿荧光；与云朵底 `#EAF3FF` 协调  
- [ ] 满级是 **圆冠 + 矮盆**，不要尖塔/圣诞树  
- [ ] 四阶段 **同一花盆、同一色板**，只变植株  
- [ ] 单叶与阶段图中的叶片 **形状一致**（同角色）  
- [ ] 无文字、无 logo、无水印

## 9. 产出物与接入路径

### 建议落盘

```text
src/assets/pc/plant/
  stage-0.png      # 空盆/芽
  stage-1.png      # 小苗
  stage-2.png      # 成长期
  stage-3.png      # 满级
  leaf.png         # 单叶精灵
  flower.png       # 可选
```

### 与代码的对应关系

| leafCount / stage | 使用素材 |
|-------------------|----------|
| 0–1 · seed | `stage-0.png` |
| 2–10 · sprout | `stage-1.png` + 可选逐叶补 |
| 11–45 · leafy | `stage-2.png` 为底 + `leaf.png` 逐叶 |
| 46–60 · full | `stage-3.png` 或 `leaf` 密铺 + `flower.png` |

### 实现要点（一片一片长）

1. `plant-core` 的 `leafCount` **不改**  
2. `plant-view` 增加 `renderPlantAssets()`：按 stage 贴整图  
3. 阶段内每 +1 叶，在茎节点 `appendChild` 一个 `leaf.png`  
   - 左右交替、上下错开、旋转 ±15°  
   - 新叶 0.4s `scale-in`  
4. 当前 SVG 渲染保留为 **无素材兜底**

## 11. 备选方案 B / C（同结构，替换角色描述即可）

### B · 小琴叶榕（替换 §3）

```text
同一株小琴叶榕盆栽：陶土色圆润小花盆，浅色口沿，深色营养土，
主干细而挺，提琴形大叶、叶脉清晰，边缘波浪，
主色 #5BBF7A 到 #3F9A62，茎 #4A7A55，盆 #E8B48A
```

阶段正文中的「圆叶」改为「提琴形叶」，其余结构不变。

### C · 多肉拼盘（替换 §3）

```text
同一株多肉拼盘：陶土色矮圆盆，浅色口沿，颗粒土，
莲座状肉质叶，叶尖略粉，层层叠叠，
主色 #7ED99A 到 #5BBF7A，叶尖 #FFB7C5，盆 #E8B48A
```

阶段：空盆 → 单头小莲座 → 多头爆盆 → 大冠幅满盆；叙事仍按使用时长「养大」。

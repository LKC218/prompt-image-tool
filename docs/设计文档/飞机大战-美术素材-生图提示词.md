# 飞机大战美术素材生图提示词

> 用途：在 GPT 网页使用 **GPT Image 2.5** 生成飞机大战透明底 Sprite。
> 对应功能：侧栏「摸鱼时间」→ 飞机大战（`/plane`）。
> 更新：2026-09-16

---

## 1. 使用说明

| 项 | 说明 |
| --- | --- |
| 模型 | GPT 网页 · GPT Image 2.5 |
| 背景 | 必须透明（alpha PNG），无地面、无投影、无画框 |
| 朝向 | 玩家机机头 **朝上**；敌机机头 **朝下**；子弹与速度方向一致 |
| 构图 | 单物体居中，正方形画布，便于裁切 |
| 建议尺寸 | 先出 1024×1024，游戏内缩到约 28–36px 宽 |
| 命名 | 见文末「落地命名」 |
| 建议目录 | `src/assets/pc/games/plane/` |

### 公共后缀（每条提示词末尾拼接）

```text
2D game sprite asset, top-down vertical shooter style, single object centered,
fully transparent background (alpha PNG, no backdrop, no ground, no drop shadow),
crisp clean silhouette, soft rounded cartoon shapes, thick readable outline,
flat shading with simple highlights, mobile-game quality,
no text, no watermark, no border, no frame, square composition
```

### 风格锁定句（多张同套时每条前缀）

```text
same art direction as a soft cute pastel arcade shooter, consistent line weight
```

## 6. 透明底失败时的补救

若 GPT 仍返回白底/场景底，可在原提示后追加：

```text
alpha transparency only, checkerboard background removed,
pure cutout sprite, no painted backdrop, no vignette
```

下载后仍不干净时，用抠图工具去底，确认 PNG 带 alpha 通道再入工程。

## 7. 落地命名与接入

| 资源 | 建议文件名 | 游戏内用途 |
| --- | --- | --- |
| 玩家机 | `player.png` | 替换 `pc-plane.js` 中蓝色三角 |
| 普通敌机 | `enemy-basic.png` | `type: 'basic'` |
| 高速敌机 | `enemy-fast.png` | `type: 'fast'` |
| 重型敌机 | `enemy-heavy.png` | `type: 'heavy'` |
| 玩家子弹 | `bullet-player.png` | 黄色弹道 |
| 敌方子弹 | `bullet-enemy.png` | 可选 |
| 爆炸 | `fx-explosion.png` | 命中/击毁特效 |
| 尾焰 | `fx-thruster.png` | 玩家尾部 |

### 接入注意

1. 贴图宽高与 `plane-war-core.js` 中 `w`/`h` 碰撞盒对齐或略小于碰撞盒。
2. 玩家机朝上、敌机朝下，不要在代码里再旋转 180°（除非素材方向固定错误）。
3. 深色战场（`#0f172a`）上优先高对比轮廓，避免过暗描边。
4. 资源放入后同步 `docs/模块说明/摸鱼时间游戏中心模块.md` 与代码地图（若改运行时加载）。

## 8. 验收清单

- [ ] 背景透明，无白边/黑边残留
- [ ] 无文字、水印、外框、投影
- [ ] 玩家机朝上，三类敌机朝下且色相区分明显
- [ ] 子弹在深色底上可辨识
- [ ] 整套线宽与赛璐璐阴影风格一致
- [ ] 导出 PNG，游戏内缩放后不糊、不抢碰撞面积

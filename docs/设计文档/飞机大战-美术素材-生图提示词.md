# 飞机大战美术素材生图提示词

> 用途：在 GPT 网页使用 **GPT Image 2.5** 生成飞机大战透明底 Sprite。
> 对应功能：侧栏「摸鱼时间」→ 飞机大战（`/plane`）。
> 更新：2026-09-16（对齐 App 整体 UI 风格）

---

## 0. 为什么旧图会「突兀」

| 旧提示词倾向 | 与 App 冲突点 | 本版修正 |
| --- | --- | --- |
| `thick readable outline` | 黑粗描边像街机贴纸，贴在浅色新拟态壳上很跳 | 改为极细软描边 / 无描边，靠明暗塑形 |
| 高饱和霓虹色 | 品牌主色是天空蓝 `#2477D4`，背景是 `#F7F9FC` 浅雾灰 | 压低饱和，主色对齐品牌蓝，敌机用粉/黄/紫的软色 |
| 硬赛璐璐块面 | App 插画（柯基、云、欢迎区）是圆润软过渡 | 改为柔和渐变 + 圆角玩具感 |
| 街机写实军机 | 产品气质是本地提示词管家的「摸鱼」软萌 | 改为圆润玩具战机 / 桌面摆件感 |

**目标气质一句话**：和侧栏柯基、欢迎区云朵同一套「圆角软胶玩具 + 品牌天蓝」的竖版射击小精灵。

## 1. 使用说明

| 项 | 说明 |
| --- | --- |
| 模型 | GPT 网页 · GPT Image 2.5 |
| 背景 | 必须透明（alpha PNG），无地面、无投影、无画框 |
| 朝向 | 玩家机机头 **朝上**；敌机机头 **朝下**；子弹与速度方向一致 |
| 构图 | 单物体居中，正方形画布，便于裁切 |
| 建议尺寸 | 先出 1024×1024，游戏内缩到约 28–36px 宽 |
| 命名 | 见文末「落地命名」 |
| 建议目录 | `src/assets/pc/games/plane/` |
| 战场底色 | 代码里是深蓝墨夜（约 `#0F172A`），素材需在深底上可辨，但 **自身仍保持 App 的软亮色**，不要做成霓虹灯 |

### 公共风格锁（每条提示词都拼接）

```text
Style lock for PromptImageManager companion minigame:
soft rounded toy-like 2D game sprite, matches a cute corgi productivity app UI,
very thin soft dark-navy outline or almost no outline (NO thick black comic outline),
soft pastel colors, brand sky blue #2477D4 as the player family hue,
muted saturation (not neon, not hyper-contrast arcade),
smooth soft gradients and gentle specular highlights like soft plastic / marshmallow,
kawaii desk-toy proportions, readable at 32px,
top-down vertical shooter sprite, single object centered,
fully transparent background (alpha PNG, no backdrop, no ground shadow, no frame),
no text, no watermark, square composition
```

### 多张同套时的额外前缀

```text
Matched set, same line weight, same soft-plastic material, same pastel family
```

### 反面清单（写进提示词可加强）

```text
Avoid: thick black outlines, neon glow, realistic military aircraft,
harsh cel-shade blocks, noisy texture, drop shadows baked into PNG
```

## 6. 透明底失败时的补救

若仍返回白底/场景底，追加：

```text
alpha transparency only, checkerboard removed, pure cutout sprite,
no painted backdrop, no vignette, no baked drop shadow
```

下载后用抠图确认 PNG 带 alpha 再入工程。

## 7. 落地命名与接入

| 资源 | 文件名 | 游戏内用途 |
| --- | --- | --- |
| 玩家机 | `player.png` | 替换 Canvas 玩家机 |
| 普通敌机 | `enemy-basic.png` | `type: 'basic'` |
| 高速敌机 | `enemy-fast.png` | `type: 'fast'` |
| 重型敌机 | `enemy-heavy.png` | `type: 'heavy'` |
| 玩家子弹 | `bullet-player.png` | 玩家弹道 |
| 敌方子弹 | `bullet-enemy.png` | 可选 |
| 爆炸 | `fx-explosion.png` | 命中/击毁 |
| 尾焰 | `fx-thruster.png` | 玩家尾部 |

### 接入注意

1. 覆盖目录：`src/assets/pc/games/plane/`（保持上述英文文件名，勿再用 ChatGPT 长名）。
2. 入库前裁透明边，机图长边约 256px，弹/特效约 128px。
3. 敌机若机头朝上，绘制层已会旋转 180°；**请尽量直接出「机头朝下」**，减少变形。
4. 深色战场上：素材自身保持软亮色即可，不要再加外发光滤镜。
5. 换图后跑 `npm run build` 确认资源打入 `dist/assets/`。

## 8. 验收清单（按 App 风格）

- [ ] 背景透明，无白边/黑边、无烘焙投影
- [ ] **无粗黑描边**，轮廓靠细发丝线或明暗
- [ ] 玩家机明显是品牌天空蓝家族，不偏军绿/霓虹青
- [ ] 敌机粉 / 黄 / 紫为 **低饱和软色**，同一套材质
- [ ] 子弹与爆炸是「棉花糖软光」，不是激光霓虹
- [ ] 与侧栏柯基、欢迎区云朵放在同一屏时不打架
- [ ] 32px 缩略下仍能认出是飞机/弹
- [ ] 整套线宽与软胶材质一致

---

## 9. 出图后若仍不统一的微调方向

1. **再降饱和**：追加 `even softer pastel, closer to #EEF3F8 background harmony`。
2. **描边仍太重**：追加 `no black ink line, only soft depth from shading`。
3. **太写实**：追加 `vinyl toy / soft PVC collectible, not concept-art aircraft`。
4. **和柯基更贴**：追加 `same vibe as a cute corgi mascot illustration, rounded chibi forms`。

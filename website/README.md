# 提示词管家官网

用于介绍软件能力的独立亮色官网初版。参考 [Sean Currlin 的网站](https://seancurrlin.com/) 的左右首屏、动态标题、三维房间、错落作品网格和纵向内容节奏；工作室由原创几何体构建，不包含参考站的品牌、履历、原始模型或音频。

## 本地运行

在项目根目录执行：

```powershell
npm ci --prefix website
npm --prefix website run dev
```

打开 `http://127.0.0.1:5180/`。仅监听回环地址，不启动 Python 服务，不读取真实提示词数据。原软件的 `5173` 开发服务、`src/` 和根目录 `dist/` 不受影响。

## 构建和检查

```powershell
npm --prefix website run build
# 单元测试与验证脚本复用根项目已有的 jsdom；先在项目根目录 npm ci。
npm --prefix website test
node scripts/verify-website.mjs --http
```

构建产物位于 `website/dist/`，可整体上传到静态托管服务；资源使用相对路径，兼容子目录部署。生产本地预览命令是 `npm --prefix website run preview`，也使用 `5180`，先停止同端口开发服务。此初版未自动部署、未改动发布流程、未发布安装包。

## 内容和交互

- 首屏：动态关键词、浅色三维工作室，鼠标跟随、横向拖动与重置视角。
- 功能：提示词、版本历史、图片处理、目标计划、局域网同步。
- 产品截图可放大，原生对话框支持 Esc、焦点归还与背景滚动锁定。
- 移动导航支持收起、Esc 和返回焦点；FAQ 使用原生 `details/summary`。
- 下载前往现有 GitHub Releases；项目版本从根目录 `package.json` 读取，不把项目版本冒充所有平台最新安装包版本。
- 系统减少动态效果优先，另有手动暂停。三维工作室静止、离屏或标签页隐藏时不持续渲染；没有 WebGL 时显示静态产品截图。

## 资源与数据边界

只在构建时复用 `docs/assets/readme/` 的公开截图和图标，以及根 `package.json` 的版本号。网页不调用业务 API、不写本地存储、不埋点、不收集表单信息。若未来需要脱离主仓库单独开发，可将这些公开资源和版本元数据复制成官网发布输入；目前无需添加运行时接口。

界面预览是已有公开资料，不声称等同于最新构建的每个像素；图片处理与同步的能力边界写在 FAQ。与参考站的对应是构图和交互语言，不是像素级完全一致：暗色改为亮色，个人履历改为产品功能，联系表单改为真实下载入口。

## 验收边界

- `website/tests/website.test.mjs`：七项结构、链接、内容边界、资源与隐私检查；构建后运行。
- `scripts/verify-website.mjs`：生产目录白名单、本地 HTTP 和文档完整性，报告保存在已忽略的 `output/website/`。
- 浏览器另行验证桌面、手机、导航、预览弹窗、FAQ 和三维渲染；静态检查不代替视觉或交互验收。

03 / 使用之前

你可能想知道。

它是一个 AI 生图工具吗？+

不是。提示词管家用来整理和复用提示词、参考图片与创作参数，不直接提供 AI 图片生成服务。你可以将收藏的提示词复制到自己使用的创作工具中。

我的数据存在哪里？+

软件采用本地优先的存储方式，创作资料保存在自己的设备上。请定期使用导出和备份功能；局域网同步不等同于备份，也不代表公网云同步。

支持哪些设备？需要安装开发环境吗？+

提供 Windows 和 Android 安装包，普通用户无需安装 Python 或前端开发依赖。Web 版本用于开发运行，不是已托管的在线账户服务。Android 的可用版本以发布页实际附件为准。

图片处理都是无损的吗？+

不是所有处理都无损。图片优化、格式转换和尺寸调整是不同操作，缩放会改变像素，JPEG 缩放会重新编码。PC 图片处理保留原图，输出独立副本。

手机和电脑怎样同步？+

让 PC 与 Android 处于同一局域网，在手机端填写 PC 服务地址并完成配对。可以从 PC 拉取、回传或双向同步；连接时以 PC 显示的实际 IP 和端口为准。
